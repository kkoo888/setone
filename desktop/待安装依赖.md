# Live2D 桌面宠物 - 待安装依赖

## 必需依赖

Live2D 渲染需要以下两个包，安装后即可启用完整的 Live2D 桌面宠物功能：

```bash
npm install pixi.js pixi-live2d-display
```

### pixi.js
- 版本要求：^7.x（推荐 7.3.x）
- 说明：2D 渲染引擎，用于创建 canvas 和渲染 Live2D 模型
- 文档：https://pixijs.com/

### pixi-live2d-display
- 版本要求：^0.4.x
- 说明：Live2D Cubism 模型的 pixi.js 显示插件
- 文档：https://github.com/guansss/pixi-live2d-display
- 注意：使用 `pixi-live2d-display/cubism4` 子路径导入（支持 Cubism 4 SDK）

## 安装命令

```bash
cd /root/setone/desktop
npm install pixi.js pixi-live2d-display
```

## 已完成的实现

以下代码已实现完毕，安装依赖后即可使用：

1. **Live2DManager.ts** - 渲染核心（pixi.js Application + 模型加载 + 鼠标追踪）
2. **Live2DCanvas.tsx** - React 渲染组件（canvas 挂载 + resize 处理）
3. **Live2DContext.tsx** - 状态管理 Provider
4. **ipc-handlers.ts** - 透明窗口 IPC 接口
5. **Live2DPetPage.tsx** - 独立宠物窗口页面
6. **main.tsx** - Hash 路由支持
