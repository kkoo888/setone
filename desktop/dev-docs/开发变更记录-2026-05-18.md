### 🎨 模块头部统一（05:33）

**背景**：翻译面板使用了 `ModuleHeader` 统一组件，但其他模块仍用自定义头部，且分割线缺失或粗细不一。

**修改内容**：将 5 个页面统一改为使用 `ModuleHeader` 组件（`src/renderer/src/components/common/module/ModuleHeader.tsx`），自带 `border-bottom: 1px solid var(--color-border)` 统一分割线。

| 文件 | 改动说明 |
|------|----------|
| `src/renderer/src/pages/SettingsPage.tsx` | `settings-page-header` → `<ModuleHeader icon="⚙️" title="设置" />` |
| `src/renderer/src/pages/ModulesPage.tsx` | `modules-header` → `<ModuleHeader icon="🧩" title="模块管理" />`，搜索栏移入 actions |
| `src/renderer/src/pages/ShortcutsPage/index.tsx` | `shortcuts-header` → `<ModuleHeader icon="⌨️" title="快捷指令" />`，添加按钮移入 actions |
| `src/renderer/src/pages/SystemDashboardPage/index.tsx` | `dash-header` → `<ModuleHeader icon="📊" title="系统仪表盘" />`，控制区移入 actions |
| `src/renderer/src/pages/SkillsPage/SkillsPage.tsx` | `skills-header` → `<ModuleHeader icon="✨" title="技能" />`，操作按钮组移入 actions |

**统一后效果**：
- 所有模块页面头部样式一致（图标 + 标题 + 右侧操作区）
- 分割线统一为 `1px solid var(--color-border)`，不再缺失或过粗
- 页面容器统一添加 `mod-page` class
