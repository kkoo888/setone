## 一、概述

### 1.1 目标

将现有的极简 skill 模块（仅 discovery + list）重构为**完整的技能生命周期管理平台**，涵盖技能的创造、发现、组织、质量把关、配置执行、统计反馈六大能力域。

### 1.2 功能清单（14 项，零冗余）

| 编号 | 功能 | 优先级 | 阶段 |
|------|------|--------|------|
| F01 | 生成新技能（AI 辅助） | P0 | 一轮 |
| F02 | 炼化迭代优化 | P0 | 一轮 |
| F03 | 激活 / 停用（开关切换） | P0 | 一轮 |
| F04 | 删除（带回收站） | P1 | 二轮 |
| F05 | 本地发现（扫描 SKILL.md） | P0 | 一轮 |
| F06 | 在线安装（市场 + URL + 更新三合一） | P1 | 二轮 |
| F07 | 标签分类 | P0 | 一轮 |
| F08 | 搜索过滤 | P0 | 一轮 |
| F09 | 技能详情页 | P0 | 一轮 |
| F10 | 安装前自动扫描（安全 + 依赖 + 兼容 + 权限声明） | P0 | 一轮 |
| F11 | 参数配置 | P1 | 二轮 |
| F12 | 技能组合 / 工作流 | P2 | 三轮 |
| F13 | 使用统计 | P2 | 三轮 |
| F14 | 导入 / 导出 | P1 | 二轮 |

### 1.3 安全设计：权限声明系统

每个技能在 SKILL.md 头部声明所需权限，安装前自动扫描时校验并提示用户：

```yaml
permissions:
  - file.read        # 读取文件
  - file.write       # 写入文件
  - network          # 网络请求
  - exec             # 执行系统命令
  - screen           # 截屏/录屏
  - clipboard        # 剪贴板
  - notification     # 系统通知
```

未声明的权限在运行时由 `capability-arbiter` 拦截。

## 二、UI 设计规范

### 2.1 设计风格参考

基于用户提供的 WorkBuddy 技能管理界面，采用 **B 端简洁高效风格**：

- 配色：白 / 黑 / 浅灰为主，蓝紫色（`#4940D4`）为强调色
- 圆角：胶囊形开关、8-12px 卡片圆角
- 字体：无衬线（系统默认），层级清晰（主标题 > 副标题 > 名称 > 描述）
- 间距：16-20px 内边距，52-56px 行高，8px 项间距

```ts
// stores/useSkillStore.ts
import { create } from 'zustand'

interface SkillMeta {
  id: string
  name: string
  description: string
  version: string
  author: string
  path: string
  icon?: string
  tags: string[]
  permissions: Permission[]
  level: 'meta' | 'description' | 'full'
  active: boolean           // 是否激活
  installSource: 'local' | 'market' | 'url'
  installedAt: number       // 安装时间戳
  lastUsedAt?: number       // 最后使用时间
  useCount: number          // 使用次数
  avgDuration?: number      // 平均耗时(ms)
}

type Permission = 'file.read' | 'file.write' | 'network' | 'exec'
  | 'screen' | 'clipboard' | 'notification'

interface ScanResult {
  safe: boolean
  permissions: { permission: Permission; risk: 'low' | 'medium' | 'high'; note: string }[]
  dependencies: { name: string; satisfied: boolean; hint?: string }[]
  compatibility: { compatible: boolean; reason?: string }
  warnings: string[]
}

interface SkillState {
  skills: SkillMeta[]
  activeTag: string
  searchQuery: string
  selectedSkill: string | null
  scanResult: ScanResult | null
  loading: boolean

  // Actions
  loadSkills: () => Promise<void>
  toggleSkill: (id: string) => Promise<void>
  deleteSkill: (id: string) => Promise<void>
  setActiveTag: (tag: string) => void
  setSearchQuery: (query: string) => void
  setSelectedSkill: (id: string | null) => void
  createSkill: (params: CreateSkillParams) => Promise<SkillMeta>
  refineSkill: (id: string, instruction: string) => Promise<void>
  installFromUrl: (url: string) => Promise<ScanResult>
  installFromMarket: (slug: string) => Promise<ScanResult>
  scanSkill: (path: string) => Promise<ScanResult>
  updateSkillConfig: (id: string, config: Record<string, unknown>) => Promise<void>
  exportSkill: (id: string) => Promise<string>  // 返回 zip 路径
  importSkill: (path: string) => Promise<SkillMeta>
}

interface CreateSkillParams {
  name: string
  description: string
  tags: string[]
  permissions: Permission[]
  template?: 'blank' | 'from-existing'
  basedOn?: string          // 基于现有技能的 id
  aiInstruction?: string    // AI 生成指令
}
```

### 3.3 页面主组件

```tsx
// pages/SkillsPage/SkillsPage.tsx
export function SkillsPage() {
  const { skills, activeTag, searchQuery, loading, setActiveTag, setSearchQuery, toggleSkill, setSelectedSkill } = useSkillStore()

  const filteredSkills = useSkillFilter(skills, activeTag, searchQuery)
  const allTags = useMemo(() => {
    const tags = new Set<string>()
    skills.forEach(s => s.tags.forEach(t => tags.add(t)))
    return ['全部', ...Array.from(tags)]
  }, [skills])

  return (
    <div className="skills-page">
      {/* 顶部标题区 */}
      <div className="skills-header">
        <div className="skills-title-group">
          <h1 className="skills-title">技能</h1>
          <p className="skills-subtitle">赋予助手更强大的能力</p>
        </div>
        <div className="skills-actions">
          <SkillSearch value={searchQuery} onChange={setSearchQuery} />
          <button className="btn-add-skill" onClick={() => openCreateDialog()}>
            <span>+</span> 添加技能
          </button>
        </div>
      </div>

      {/* 二级导航 */}
      <div className="skills-nav">
        {['推荐', 'SkillHub', '套件'].map(tab => (
          <button key={tab} className={`skills-nav-tab ${activeTab === tab ? 'active' : ''}`}
            onClick={() => setActiveTab(tab)}>
            {tab}
          </button>
        ))}
      </div>

      {/* 分类标签栏 */}
      <SkillTags tags={allTags} active={activeTag} onChange={setActiveTag} />

      {/* 技能网格 */}
      <div className="skills-grid">
        {filteredSkills.map(skill => (
          <SkillCard key={skill.id} skill={skill}
            onToggle={(id) => toggleSkill(id)}
            onClick={(id) => setSelectedSkill(id)} />
        ))}
      </div>

      {/* 详情侧滑面板 */}
      {selectedSkill && <SkillDetail skillId={selectedSkill} onClose={() => setSelectedSkill(null)} />}
    </div>
  )
}
```

## 五、IPC 通信协议

前端通过已有的 `window.electronAPI.invoke` 调用后端能力：

| IPC 通道 | 参数 | 返回值 | 说明 |
|----------|------|--------|------|
| `skill:list` | `{}` | `SkillMeta[]` | 获取全部技能 |
| `skill:toggle` | `{ id, active }` | `{ id, active }` | 激活/停用 |
| `skill:create` | `CreateSkillParams` | `SkillMeta` | 创建新技能 |
| `skill:refine` | `{ id, instruction }` | `SkillMeta` | 炼化优化 |
| `skill:delete` | `{ id }` | `{ success }` | 删除技能 |
| `skill:install` | `{ source, slug?, url? }` | `ScanResult` | 安装技能 |
| `skill:scan` | `{ path }` | `ScanResult` | 安装前扫描 |
| `skill:config:get` | `{ id }` | `Record` | 获取配置 |
| `skill:config:set` | `{ id, config }` | `{ success }` | 更新配置 |
| `skill:stats` | `{ id? }` | `SkillStats[]` | 使用统计 |
| `skill:export` | `{ id }` | `{ path }` | 导出 zip |
| `skill:import` | `{ path }` | `SkillMeta` | 导入技能 |
