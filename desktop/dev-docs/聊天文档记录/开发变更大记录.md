### 🔴 宠物窗口打不开 — IPC Handler 缺失修复

| 变更项 | 详情 |
|--------|------|
| 问题 | `Live2D5Page` 调用 `invoke('live2d5_open')` 无响应，主进程没有注册对应 handler |
| 根因 | `getCapabilities()` 只注册 AI 工具，没有注册 renderer 可调用的 IPC handler |
| 修复 | 新增 `registerIPCHandlers()` 注册 6 个 `ipcMain.handle`，deactivate 时 `removeHandler` 注销 |
| 影响 | `live2d5_open`、`live2d5_close`、`live2d5_status`、`live2d5_expression`、`live2d5_motion`、`live2d5_start_drag` |

### 🔴 知识库数据集下载修复

| 变更项 | 详情 |
|--------|------|
| 问题 | 数据集下载进度条一直为 0，文件大小为 0 |
| 根因1 | `setupSessionListener(session)` 从未调用，`will-download` 事件无监听 |
| 根因2 | 数据集 URL 是网页链接而非直接下载链接 |
| 修复1 | `activate()` 中调用 `setupSessionListener(session.defaultSession)` |
| 修复2 | 重写 `startDownload()` 为 async，自动查询 ModelScope API 获取真实下载 URL |
| 新增方法 | `parseModelScopeUrl()` — 解析页面 URL；`resolveDownloadUrl()` — 查询文件列表 API |
| API格式 | 文件列表：`/api/v1/datasets/{owner}/{name}/repo/tree?Revision=master`；下载：`/api/v1/datasets/{owner}/{name}/repo?Revision=master&FilePath={file}` |
| 修改文件 | knowledge-base/index.ts, DatasetDownloader.ts |
