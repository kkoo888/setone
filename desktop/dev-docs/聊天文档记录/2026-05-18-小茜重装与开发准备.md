#### 核心编码规范（P3C 适配 TypeScript）

| 类别 | 规范 |
|------|------|
| 命名 - 类/接口/类型 | PascalCase，不加 `I` 前缀 |
| 命名 - 方法/变量 | camelCase，布尔值以 `is/has/should/can` 开头 |
| 命名 - 常量 | UPPER_SNAKE_CASE |
| 类型安全 | 禁止 `any`，使用 `unknown` |
| 比较 | 使用 `===` / `!==` |
| 空值安全 | 启用 `strictNullChecks` |
| 方法长度 | 单方法 ≤ 80 行 |
| 嵌套深度 | if/for 最多 3 层嵌套 |
| 魔法数字 | 禁止，必须提取为命名常量 |
| 注释 | TSDoc 注释必须 |

### 任务 5：设置 45 分钟定时自动提交 ✅

设置 cron job，在 45 分钟后自动执行 Git 提交操作：

| 配置项 | 内容 |
|--------|------|
| **触发时间** | 设置后 45 分钟（约 2026-05-18 19:26 CST） |
| **操作内容** | 检查 desktop/ 变更 → 提交到 dev → 合并到 main → 推送远程 |

#### 执行流程

1. `cd /root/.openclaw/workspace/setone/desktop/`
2. `git add .` — 暂存所有变更
3. `git commit -m "auto: 定时提交开发变更"` — 提交到 dev 分支
4. `git checkout main && git merge dev` — 合并到 main 分支
5. `git push origin dev main` — 推送到远程仓库
6. `git checkout dev` — 切回 dev 分支

> **关键决策**：定期自动提交防止开发成果丢失。
