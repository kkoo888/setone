#### 7. 宠物窗口打不开 — 根本原因修复

主人发现点击「打开宠物窗口」按钮无反应。经排查发现根本原因：

**问题：** `Live2D5Page` 调用 `window.electronAPI.invoke('live2d5_open')`，但主进程 `ipc-handlers.ts` 中没有注册对应的 `ipcMain.handle('live2d5_open', ...)`，导致静默失败。

**原因分析：** 模块的 `getCapabilities()` 只注册了 AI 工具（给 LLM 调用），没有注册 IPC handler（给 renderer 直接调用）。两条通路缺了一条。

**修复：** 在模块 `index.ts` 中新增 `registerIPCHandlers()` / `unregisterIPCHandlers()`，注册 6 个 IPC handler：
- `live2d5_open` — 打开宠物窗口
- `live2d5_close` — 关闭宠物窗口
- `live2d5_status` — 查询状态
- `live2d5_expression` — 切换表情
- `live2d5_motion` — 播放动作
- `live2d5_start_drag` — 拖拽

activate 时注册，deactivate 时注销，遵循模块生命周期。

#### 8. 知识库数据集下载修复

主人发现数据集广场点击下载后进度条一直是 0，文件大小也检查不回来。

**根本原因：**
1. `setupSessionListener(session)` 从未被调用 — 没有它 Electron 的 `will-download` 事件不会被捕获
2. 数据集 URL 是 ModelScope 网页链接，不是直接下载链接 — `webContents.downloadURL()` 会下载 HTML 页面

**修复：**
1. 在 `activate()` 中添加 `this.datasetDownloader.setupSessionListener(session.defaultSession)`
2. 重写 `startDownload()` — 接收页面 URL，自动查询 ModelScope 文件列表 API，找到主数据文件并构造下载 URL
3. 新增 `parseModelScopeUrl()` — 从页面 URL 解析 owner/name
4. 新增 `resolveDownloadUrl()` — 查询 `GET /api/v1/datasets/{owner}/{name}/repo/tree?Revision=master`，优先选 .zip/.tar.gz/.jsonl 等数据文件
5. 下载 URL 格式：`GET /api/v1/datasets/{owner}/{name}/repo?Revision=master&FilePath={filename}`

**修改文件：** `knowledge-base/index.ts`（+4行），`DatasetDownloader.ts`（+113行）
