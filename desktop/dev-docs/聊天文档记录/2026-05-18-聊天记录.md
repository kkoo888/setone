## 项目结构

setone 是一个基于 **Electron + Vite + TypeScript** 的桌面应用项目，采用自定义模块加载架构，支持热插拔。

```
desktop/
├── src/                    # 主源码
│   ├── main/               # 主进程
│   ├── preload/            # 预加载脚本
│   ├── renderer/           # 渲染进程
│   └── shared/             # 共享代码
├── modules/                # 功能模块
├── dev-docs/               # 开发文档
│   └── 聊天文档记录/       # 每日聊天记录归档
└── package.json
```
