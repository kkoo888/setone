### 核心编码规范（P3C 适配 TypeScript）

- 类/接口/类型：PascalCase，不加 `I` 前缀
- 方法/变量：camelCase，布尔值以 `is/has/should/can` 开头
- 常量：UPPER_SNAKE_CASE
- 禁止魔法数字，必须提取为命名常量
- 禁止 `any`，使用 `unknown`
- 单方法 ≤ 80 行
- if/for 最多 3 层嵌套
- 使用 `===` / `!==`
- 启用 `strictNullChecks`
- TSDoc 注释必须
