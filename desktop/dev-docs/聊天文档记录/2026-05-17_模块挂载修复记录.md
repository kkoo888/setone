## 问题描述
模块能被扫描出来，但全部挂载不成功，显示异常。

## 根因分析

### 直接原因
`file` 和 `input` 两个模块的 `module.json` 中 `dependencies` 字段错误地填写了 **npm 包名**而非**模块 ID**：

| 模块 | dependencies | 问题 |
|------|-------------|------|
| `file` | `["chokidar"]` | `chokidar` 是 npm 包，不是模块 ID |
| `input` | `["robotjs"]` | `robotjs` 是 npm 包，不是模块 ID |

### 影响链路
1. `ModuleScanner` 正常扫描到 13 个模块
2. `DependencyResolver.resolve()` 检查依赖时，`chokidar` 和 `robotjs` 不在已注册模块 ID 列表中
3. `file` 和 `input` 被标记为 `DependencyError { type: 'missing' }`
4. 这两个模块从 `resolution.order` 中排除
5. `ModuleManager.initialize()` 遍历 `resolution.order` 时，这两个模块永远不会被激活

### npm 包使用情况
- `chokidar`：在 `file/services/file-watcher.ts` 中通过 `await import('chokidar')` 动态加载，仅在 `watch()` 被调用时使用，不影响模块初始化
- `robotjs`：在 `input/services/mouse.ts` 中全部被注释掉，完全未使用

## 修复方案

### 1. 修复 module.json
- `file/module.json`：`dependencies: ["chokidar"]` → `dependencies: []`
- `input/module.json`：`dependencies: ["robotjs"]` → `dependencies: []`
