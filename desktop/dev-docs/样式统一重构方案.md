# 样式统一重构方案

> 日期：2026-05-20
> 状态：进行中

---

## 一、发现的问题

### 🔴 Bug：仪表盘无法滚动

**根因**：`.dash-page` 设置了 `height: 100%; overflow-y: auto`，但被父级 `.mod-page` 的 `overflow: hidden` 覆盖，导致内容被裁剪无法滚动。

**影响**：仅仪表盘页面。其他15个使用 `mod-page` 的页面均有内部滚动容器（CSS 或内联样式），不受影响。

**修复**：
- `dashboard.css`：去掉 `.dash-page` 的 `height: 100%` 和 `overflow-y: auto`
- `SystemDashboardPage.tsx`：新增 `.dash-content` 内部滚动容器

### 🟡 设计不一致：设置页面靠外层滚动

设置页面没有内部滚动容器，依赖 `.page-container { overflow: auto }` 接管滚动。目前能正常工作，但与其他15个页面模式不一致。

**建议**：后续迭代时统一加内部滚动容器。

### 🟡 内联样式泛滥

全项目 20+ 个 TSX 文件中存在 ~265 处内联样式，其中 ~216 处为静态样式应迁移到 CSS。

### 🟡 硬编码值未统一

字号、间距、颜色等存在大量硬编码值（如 `12px`、`24px`、`#e74c3c`），未使用 CSS 变量。

## 二、修复方案

### 2.1 设计变量补全（`variables.css`）

新增变量：

| 类别 | 变量 | 值 | 用途 |
|------|------|-----|------|
| 间距 | `--spacing-2xs` | 2px | 极小间距 |
| 间距 | `--spacing-xs-sm` | 6px | xs和sm之间 |
| 间距 | `--spacing-sm-md` | 10px | sm和md之间 |
| 间距 | `--spacing-md-lg` | 20px | md和lg之间 |
| 间距 | `--spacing-2xl` | 36px | 大间距 |
| 字号 | `--font-size-2xs` | 10px | 极小文字 |
| 字号 | `--font-size-md` | 18px | 小标题（原16px） |
| 字号 | `--font-size-lg` | 20px | 标题（原18px） |
| 字号 | `--font-size-2xl` | 28px | 模块图标 |
| 字号 | `--font-size-3xl` | 48px | 空状态图标 |
| 颜色 | `--color-text-inverse` | #ffffff | 反色文字 |
| 颜色 | `--color-accent-light` | #a78bfa | 浅强调色 |
| 颜色 | `--color-border-light` | rgba(255,255,255,0.1) | 暗色面板边框 |
| 颜色 | `--color-overlay` | rgba(0,0,0,0.4) | 遮罩层 |

### 2.2 公共工具类（`module-common.css`）

新增通用 class：

| Class | 用途 |
|-------|------|
| `.mod-scroll` | 内部滚动容器（flex:1, overflow-y:auto, padding:0 12px 12px） |
| `.flex-row` / `.flex-col` / `.flex-col-sm` | 弹性布局 |
| `.label-xs` / `.label-sm` | 标签文字 |
| `.badge-sm` / `.badge-accent` / `.badge-new` | 徽章 |
| `.overlay` | 全屏遮罩层 |
| `.modal-panel` | 弹窗面板 |
| `.status-dot-sm` | 状态指示点 |
| `.input-base` | 输入框基础样式 |
| `.form-row` / `.form-toolbar` | 表单行 |
| `.text-ellipsis` / `.text-clamp-2` | 文字溢出处理 |
| `.progress-bar` / `.progress-fill` | 进度条 |
| `.hidden` | 隐藏（visibility: hidden） |
| `.error-msg` | 错误提示 |
| `.file-info-bar` | 文件信息栏 |
| `.preview-box` | 预览容器 |

### 2.3 主内容区 padding 调整

```css
/* 修改前 */
.page-container { padding: var(--spacing-lg); }  /* 24px 四周 */

/* 修改后 */
.page-container { padding: 0 var(--spacing-lg); }  /* 去掉上下 */
```

所有页面内部滚动容器统一 padding：`0 12px 12px`
