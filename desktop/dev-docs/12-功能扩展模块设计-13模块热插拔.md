## 〇、设计原则

### 0.1 热插拔架构

每个功能模块遵循统一的模块接口规范：

```
modules/<module-id>/
├── module.json          # 模块元数据（必须）
├── index.ts             # 模块入口，实现 Module 接口（必须）
├── types.ts             # 类型定义
├── services/            # 业务逻辑层
│   ├── xxx-service.ts
│   └── ...
└── ui/                  # 前端组件（可选，通过 getUI() 暴露）
    ├── XxxPanel.tsx
    └── ...
```

### 0.2 模块生命周期

```
discovered → loading → active ⇄ disabled
                          ↓
                        error → (retry / disabled)
```

- **discovered**：扫描到 module.json，未加载
- **loading**：正在动态导入 index.ts
- **active**：已激活，能力已注册到工具路由
- **disabled**：用户手动停用
- **error**：激活失败，自动降级

### 0.3 模块间通信

- **事件总线**：通过 `context.eventBus` 发布/订阅事件
- **工具调用**：通过 `context.invoke(capabilityName, params)` 调用其他模块的能力
- **共享存储**：通过 `context.store` 读写模块间共享数据
- **直接依赖**：在 module.json 的 `consumes` 中声明，框架注入

## 一、命令面板（command-palette）

### 1.1 模块概述

按 `Ctrl+K`（macOS: `Cmd+K`）呼出全局命令面板，支持模糊搜索快速执行：发消息、切模块、调技能、查文件、改设置、执行快捷指令。

### 1.2 module.json

```json

  "name": "命令面板",
  "version": "1.0.0",
  "description": "全局快捷命令面板，Ctrl+K 呼出，模糊搜索快速执行",
  "author": "system",
  "enabled": true,
  "dependencies": ["tools"],
  "hostVersion": ">=1.0.0",
  "priority": 5,
  "resourceLimits": { "maxMemoryMB": 64, "maxCpuPercent": 5 },
  "provides": [
    { "type": "tool", "name": "palette_open", "description": "打开命令面板", "priority": 5 },
    { "type": "tool", "name": "palette_register_command", "description": "注册自定义命令", "priority": 5 },
    { "type": "ui", "name": "CommandPalette", "description": "命令面板浮层组件" }

    { "type": "event", "name": "palette:open" },
```

### 1.3 能力列表

| 能力名 | 类型 | 说明 |

### 1.4 命令来源

命令面板聚合以下来源的命令：

| 来源 | 示例命令 | 注册方式 |
|------|----------|----------|
| 内置 | 切换主题、打开设置、清空聊天 | 模块 activate 时注册 |
| 技能模块 | 每个激活的技能自动注册为命令 | 监听 skill:activated 事件 |
| 快捷指令模块 | 用户自定义的 /xxx 指令 | 监听 snippet:registered 事件 |
| 模块管理 | 激活/停用模块 | 模块注册时自动添加 |
| 文件搜索 | 最近打开的文件 | 按需查询 |

```ts
interface Snippet {
  id: string
  name: string               // 指令名（如 "翻译"）
  trigger: string            // 触发词（如 "/翻译"）
  description: string
  /** 执行模式 */
  mode: 'template' | 'action' | 'chain'
  /** 模板模式：参数替换 */
  template?: string          // 如 "请将以下内容翻译为{lang}：{text}"
  /** 动作模式：调用工具 */
  action?: {
    capability: string       // 要调用的能力名
    params: Record<string, unknown>  // 固定参数
    inputMapping?: Record<string, string>  // 用户输入映射到参数
  }
  /** 链式模式：多步骤 */
  chain?: Array<{
    step: number
    capability: string
    params: Record<string, unknown>
    inputFrom?: string       // 从哪一步的输出取输入
  }>
  parameters: SnippetParam[]  // 参数定义
  category: string
  icon?: string
  createdAt: number
  useCount: number
}

interface SnippetParam {
  name: string          // 参数名
  label: string         // 显示名
  required: boolean
  defaultValue?: string
  type: 'text' | 'number' | 'select' | 'file'
  options?: string[]    // select 类型的选项
}
```

```ts
        this.lastContent = current
        this.onNewContent(current)
      }
    }, intervalMs)
  }

    // 2. 检查大小限制
    // 3. 去重（和最近一条比较）
    // 4. 保存到数据库
  }
}
```

### 3.7 安全设计

- **敏感内容过滤**：匹配 `excludePatterns` 的内容不记录
- **自动清理**：超过 `autoCleanupDays` 天且未固定的内容自动删除
- **大小限制**：单条内容超过 `maxItemSize` 截断存储
- **本地存储**：所有数据存本地 SQLite，不上传

### 13.4 数据模型

```ts
interface CalendarEvent {
  id: string
  title: string
  description?: string
  startTime: number    // ISO timestamp
  endTime: number
  allDay: boolean
  /** 提醒设置（分钟数，如 15 表示提前15分钟） */
  reminders: number[]
  /** 重复规则 */
  recurrence?: {
    type: 'daily' | 'weekly' | 'monthly' | 'yearly'
    interval: number
    endDate?: number
  }
  /** 颜色标记 */
  color?: string
  /** 来源 */
  source: 'manual' | 'ai-extracted' | 'synced'
  createdAt: number
}
```

### 13.5 AI 智能创建

在聊天中检测时间信息：

```
用户：明天下午3点开个会
AI：好的，我帮你创建一个日程 📅
    标题：会议
    时间：2026-05-17 15:00
    提醒：提前15分钟
    [确认] [修改] [取消]
```

- 自然语言时间解析（"明天下午3点" → `2026-05-17T15:00:00`）
- 和主动提醒模块（proactive）联动设置提醒
- 支持用户确认后创建，不自动操作
