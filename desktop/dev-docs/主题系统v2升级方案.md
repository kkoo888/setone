# SetOne 主题系统 v2.0 升级方案

> 整合 shadcn/ui、Chakra UI、Mantine、Ant Design、Radix 等顶级框架的优点
> 设计人：小希 🤖 | 2026-05-20

---

## 一、设计理念

**一句话**：用最少的 Seed Token，自动派生出完整的主题体系，支持全局 + 组件级定制。

**借鉴来源**：

| 框架 | 借鉴内容 |
|------|---------|
| shadcn/ui | bg/fg 语义配对、Radius 派生、侧边栏独立 Token |
| Chakra UI | 50-900 色阶系统、Alpha 透明度色板 |
| Mantine | autoContrast 自动对比度、primaryShade 亮暗适配 |
| Ant Design | 三层 Token 架构（Seed → Map → Alias） |
| Radix | 12 级灰度刻度、Scale + Semantic 双轨 |

## 三、Seed Token 定义（只需 7 个值）

```json
{
  "id": "my-theme",
  "name": "我的主题",
  "seed": {
    "accent": "#4338ca",
    "bg": "#ffffff",
    "fg": "#1a1a1a",
    "radius": 8,
    "font-base": 16,
    "spacing-base": 8,
    "mode": "light"
  }
}
```

**从这 7 个 Seed 值，自动派生出 80+ 个完整 Token。**

### Seed → Map 派生规则

```typescript
// 色阶派生（借鉴 Chakra 50-900）
function deriveColorScale(baseColor: string): ColorScale {
  return {
    50:  lighten(baseColor, 0.95),  // 最浅，背景用
    100: lighten(baseColor, 0.85),
    200: lighten(baseColor, 0.70),
    300: lighten(baseColor, 0.50),
    400: lighten(baseColor, 0.30),
    500: baseColor,                  // 基准色
    600: darken(baseColor, 0.10),    // hover 用
    700: darken(baseColor, 0.20),    // active 用
    800: darken(baseColor, 0.35),
    900: darken(baseColor, 0.50),    // 最深
  }
}

// 圆角派生（借鉴 shadcn/ui）
function deriveRadius(base: number): RadiusScale {
  return {
    sm:  base * 0.6,   // 4.8px
    md:  base * 0.8,   // 6.4px
    lg:  base,         // 8px（基准）
    xl:  base * 1.4,   // 11.2px
    '2xl': base * 1.8, // 14.4px
    full: 9999,
  }
}

// 间距派生
function deriveSpacing(base: number): SpacingScale {
  return {
    '2xs': base * 0.25,  // 2px
    xs:   base * 0.5,    // 4px
    sm:   base,           // 8px
    md:   base * 2,       // 16px
    lg:   base * 3,       // 24px
    xl:   base * 4,       // 32px
    '2xl': base * 6,      // 48px
  }
}
```

## 五、暗色模式自动生成

### 5.1 算法派生（借鉴 Mantine primaryShade）

```typescript
interface DarkModeStrategy {
  // 亮色模式用色阶 6，暗色模式用色阶 4（更亮）
  primaryShade: { light: 6, dark: 4 };
  
  // 背景色反转规则
  bgInversion: {
    light: { bg: 'white', card: 'white', muted: 'gray-100' },
    dark:  { bg: 'gray-950', card: 'gray-900', muted: 'gray-800' }
  };
  
  // 前景色自动对比度（借鉴 Mantine autoContrast）
  autoContrast: true;
  luminanceThreshold: 0.3;
}

// 暗色模式自动派生
function generateDarkTheme(seed: SeedToken): AliasTokens {
  const darkBg = invertLightness(seed.bg);    // #fff → #0a0a0f
  const darkFg = invertLightness(seed.fg);    // #1a1a1a → #e8e8e8
  
  return {
    '--bg':         darkBg,
    '--fg':         darkFg,
    '--card':       lighten(darkBg, 0.05),    // 比背景亮一点
    '--card-fg':    darkFg,
    '--primary':    colorScale(seed.accent)[4], // 暗色模式用更亮的色阶
    '--primary-fg': darkBg,
    '--border':     'var(--gray-800)',
    '--muted':      'var(--gray-800)',
    '--muted-fg':   'var(--gray-400)',
  }
}
```

### 5.2 自动对比度（借鉴 Mantine autoContrast）

```typescript
function autoContrast(bgLuminance: number): 'light' | 'dark' {
  // 背景亮度 > 阈值 → 用深色文字
  // 背景亮度 < 阈值 → 用浅色文字
  return bgLuminance > 0.3 ? 'dark' : 'light'
}

// 组件使用示例
// <Button bg="primary"> → 自动计算 primary 的亮度，决定文字用 black/white
```

## 十一、autoContrast 自动对比度（借鉴 Mantine）

```typescript
/**
 * 根据背景色自动计算前景文字颜色
 * 用户自定义主题时，不用手动配对颜色
 */
function getContrastColor(bgHex: string): string {
  const luminance = getRelativeLuminance(bgHex)
  return luminance > 0.3 ? '#1a1a1a' : '#ffffff'
}

// 组件使用
function Button({ children, variant = 'primary' }) {
  const bgColor = `var(--${variant})`
  // 自动计算文字颜色，无需手动指定 --primary-fg
  return (
    <button style={{ 
      background: bgColor,
      color: `var(--${variant}-fg, var(--auto-fg))` 
    }}>
      {children}
    </button>
  )
}
```
