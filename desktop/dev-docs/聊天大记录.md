### 21:51 - 深入 UI 组件分析
- 分析了 ChatPage、SettingsPage、StatusBar、Dashboard CSS、Workflow CSS 等组件/样式
- 发现的额外优化点：

**ChatPage.tsx：**
- `onPasteImage` 和 `onAttachFile` 回调在 JSX 中内联定义，每次渲染都创建新函数，建议提取为 `useCallback`
- 错误回退界面（ErrorBoundary fallback）缺少 `aria-live` 属性，屏幕阅读器无法感知错误状态变化
- 聊聊页面容器 `.chat-page` 缺少 `role="main"` 或 `aria-label`

**SettingsPage.tsx：**
- `<label>` 元素缺少 `htmlFor` 属性，未与对应 input 关联，影响无障碍访问
- `window.confirm()` 用于重置确认，不够现代且无障碍性差，建议替换为自定义确认弹窗
- `handleReset` 和 `handleSave` 的 `useCallback` 依赖数组为空但引用了外部函数，虽然稳定但不够严谨

**StatusBar.tsx：**
- 3000ms 轮询间隔硬编码，建议提取为配置常量
- `getColor()` 函数在组件内部定义，每次渲染重新创建，应提取到组件外部或使用 `useMemo`
- 资源数据动态更新但缺少 `aria-live="polite"` 属性，屏幕阅读器无法感知数值变化
- `try/catch` 静默失败无任何日志，调试困难

**dashboard.css：**
- 仍有多处硬编码 px 值：`12px` padding（4处）、`14px` gap（3处）、`7px` padding（2处）
- `grid-template-columns: minmax(260px, 1fr)` 和 `minmax(220px, 1fr)` 硬编码
- 多处硬编码 rgba 颜色：`rgba(99, 102, 241, 0.3)`、`rgba(0, 0, 0, 0.06)`、`rgba(34, 197, 94, 0.4)` 等
- 暗色主题适配中 `rgba(255, 255, 255, 0.06)` 等值硬编码，应使用 CSS 变量
- 进度条 shimmer 动画未考虑 `prefers-reduced-motion`

**workflow.css：**
- 大量硬编码 px 值：`6px`、`4px`、`3px`、`10px`、`14px`、`8px`、`18px`、`20px`、`44px`、`56px`、`22px`、`52px`、`80px`、`40px`、`32px` 等（20+处）
- `rgba(99, 102, 241, ...)` 魔法颜色值重复出现 15+ 次，应使用 `var(--color-accent)` 派生
- `var(--radius-lg, 16px)` 等 fallback 值说明 CSS 变量可能未完全定义
- `wfPulse` 和 `wfOverlayIn` 动画未考虑 `prefers-reduced-motion`
- 弹窗 `z-index: 1100` 硬编码，建议使用 CSS 变量管理层级
- 暗色主题适配中 rgba 值全部硬编码
