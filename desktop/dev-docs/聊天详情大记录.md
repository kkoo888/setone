```
TypeError: Cannot read properties of undefined (reading 'toString')
at new CubismShader_WebGL
at CubismShaderManager_WebGL.setGlContext
at CubismRenderer_WebGL.startUp
at AppModel.loadAssets
```

**根因分析：**
- cubismmodel.ts 的 CubismColorBlend 枚举值引用 `Live2DCubismCore.ColorBlendType_*`
- 这些值在模块加载时求值，但此时 Core SDK 尚未通过 script 标签加载
- Demo 不会有此问题（index.html 先加载 Core SDK 再加载模块代码）
- 当前模块的 Core SDK 是在运行时由 loadSDK() 动态加载的

**修复：**
- 枚举值改为硬编码数字（与 Core SDK 实际值一致）
- 0=Normal, 1=AddCompatible, 2=MultiplyCompatible, 3=Add, ...17=Color

### 18:37 - 发现问题 1：诊断日志死循环

**位置**：`cubismrenderer_webgl.ts` 第 1105 行

**问题代码**：

**分析**：
