## 2026-05-20 主题系统优化（字号梯度重整）

### 变更概述
借鉴 shadcn/ui、Ant Design、Mantine 等高星 UI 框架，对主题系统进行系统性优化。

### 字号梯度体系（新增）
| Token | 值 | 用途 |
|-------|-----|------|
| --font-size-2xs | 10px | 辅助标签、徽章 |
| --font-size-xs | 12px | 时间戳、说明文字 |
| --font-size-sm | 14px | 正文（桌面应用默认） |
| --font-size-md | 16px | 输入框、按钮 |
| --font-size-lg | 18px | 小标题 |
| --font-size-xl | 20px | 页面标题 |
| --font-size-2xl | 24px | 模块标题 |
| --font-size-3xl | 32px | 数字展示 |

### 核心变更
1. themeEngine.ts：字号从倍率派生改为固定整数梯度
2. 26 个 CSS 文件：硬编码 font-size/padding/border-radius 替换为 CSS 变量
3. button.css：新增 .btn-icon、.btn-pill 统一按钮变体
4. variables.css：清理 --font-size-md-lg 中间变量
5. 安装 3 个设计系统 skill：distinctive-design-systems、frontend-architecture-pro、design-system-patterns

### 设计借鉴
- shadcn/ui：三层 token 架构（primitive → semantic → component）
- Ant Design：fontSize 作为 seed token
- Mantine：统一字号梯度命名
- distinctive-design-systems：美学文档优先、type scale 乘数器
