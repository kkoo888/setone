```
01-项目脚手架 ──→ 02-核心类型定义 ──┬──→ 03-事件总线
                                    ├──→ 04-统一日志

                                    └──→ 06-SQLite存储层
```

## 执行流程

```
Step 1  小茜完成 01（脚手架）
           │
Step 2  小茜完成 02（核心类型）
           │
Step 3  同时派出 4 个子代理并行开发：
           ├── 子代理A → 03-事件总线
           ├── 子代理B → 04-统一日志
           ├── 子代理C → 05-配置管理器
           └── 子代理D → 06-SQLite存储层
           │
Step 4  小茜验收全部模块，集成整合
```

---

## 子代理工作规范

每个子代理启动时接收以下内容：

1. **开发文档**：对应的 `dev-docs/0X-xxx.md` 完整技术规范
2. **依赖代码路径**：`desktop/src/` 下已完成的上游模块
3. **输出目录**：`desktop/src/` 对应子目录
4. **代码规范**：项目统一 ESLint + Prettier 配置
5. **验收标准**：对应里程碑定义

---

## 代码规范（所有子代理统一）

- **文件命名**：主进程 `camelCase.ts`，组件 `PascalCase.tsx`，工具 `camelCase.ts`
- **导入顺序**：electron → 第三方库 → 内部模块 → 相对路径 → 样式
- **缩进**：2空格
- **引号**：单引号，JSX双引号
- **分号**：不加
- **组件导出**：`export default function ComponentName()`
