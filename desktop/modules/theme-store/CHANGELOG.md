# Changelog

## [2.1.0] - 2026-05-19

### Changed
- 📦 **本地主题仓库**：新增 `themes/` 目录作为主题仓库，放入 JSON 文件即可在商店中"下载"
- 📥 **导入主题**：新增 `theme_import` 工具，支持从 JSON 文件导入自定义主题
- 🗑 **删除主题**：新增 `theme_delete` 工具，可删除已导入的自定义主题（内置不可删）
- 🏷 **来源标记**：主题分为 builtin（内置）、imported（已导入）、available（可下载）三种来源
- 🔄 **自动导入**：应用"可下载"主题时自动转为已导入
- 🎯 **筛选优化**：商店筛选改为 内置/已导入/可下载/亮色/暗色

### Removed
- 🗑 移除"安装/卸载"概念（改为"下载并应用"/"删除"）

## [2.0.0] - 2026-05-19

### Changed
- 🔥 **统一主题系统**：合并明暗模式和配色主题为一套系统
- 🎨 **新增明暗模式主题**：内置亮色模式和暗色模式
- ⚙️ **设置页联动**：设置页跳转主题商店

### Fixed
- 🐛 config 类型安全、无效写入、deactivate 清理、CSS 死代码、事件格式
