### 变更5：AI 工具调用参数映射修复

- **问题现象**：LLM 不知道每个模块工具需要什么参数，导致乱传或不调用工具
- **根因分析**：`ipc-handlers.ts` 中 `collectModuleTools()` 构建工具定义时，`parameters` 固定为空 schema `{ properties: {} }`，LLM 看不到任何参数信息
- **影响范围**：14 个模块、69 个工具能力全部受影响

**修复内容**：

#### 新增：`src/main/core/tool-param-schemas.ts`（604 行）
- 创建工具参数 JSON Schema 映射表，覆盖全部 14 个模块的工具
- 支持三级回退：模块自定义参数 > 静态映射表 > 空 schema
- 每个工具包含完整的 `properties`、`required`、`description`、`type`、`enum` 等信息

#### 修改：`src/main/ipc-handlers.ts`
- 引入 `getToolParamSchema` 函数
- `collectModuleTools()` 中将空 schema 替换为动态查询：`cap.parameters ?? getToolParamSchema(cap.name)`

#### 修改：`src/main/types/capability.ts`
- `Capability` 接口新增可选字段 `parameters?: Record<string, unknown>`
- 支持模块自定义参数 schema，无需依赖静态映射

**状态**：✅ 已完成，待编译验证

## 项目结构分析

setone 是一个基于 **Electron + Vite + TypeScript** 的桌面应用项目，采用自定义模块加载架构，支持热插拔。

```
desktop/
├── src/                    # 主源码
│   ├── main/               # 主进程（Electron main process）
│   │   ├── core/           # 核心模块（含 tool-param-schemas.ts）
│   │   ├── ipc-handlers.ts # IPC 通信处理
│   │   └── types/          # 类型定义（含 capability.ts）
│   ├── preload/            # 预加载脚本
│   ├── renderer/           # 渲染进程（前端 UI）
│   └── shared/             # 共享代码
├── modules/                # 16 个功能模块（69 个工具能力）
├── dev-docs/               # 开发文档
│   └── 聊天文档记录/       # 每日聊天记录归档
├── skills/                 # 技能目录
├── tests/                  # 测试目录
├── scripts/                # 脚本目录
├── package.json            # 项目配置
├── CODING_STANDARD.md      # 编码规范（P3C 适配 TypeScript）
├── BUILD_GUIDE.md          # 构建指南
└── 多个开发规范文档
```

### 核心编码规范（P3C 适配 TypeScript）

- 类/接口/类型：PascalCase，不加 `I` 前缀
- 方法/变量：camelCase，布尔值以 `is/has/should/can` 开头
- 常量：UPPER_SNAKE_CASE
- 禁止魔法数字，必须提取为命名常量
- 禁止 `any`，使用 `unknown`
- 单方法 ≤ 80 行
- if/for 最多 3 层嵌套
- 使用 `===` / `!==`
- 启用 `strictNullChecks`
- TSDoc 注释必须
