# 33-翻译器模块（translator）

> **前置依赖**：版块31（知识库模块）
> **版块**：33
> **说明**：划词翻译、全文翻译、翻译历史，支持知识库辅助翻译

| 优先级 | 22 |
| 资源限制 | 128MB / 10% CPU |

## 核心功能

### 翻译引擎
- **大模型翻译** — 通过 Ollama 进行翻译
- **知识库辅助翻译** — `translate_with_kb`：优先从知识库查找已有翻译，未命中再调用大模型（"小希翻译"）
- **语言检测** — 自动检测源语言

### 翻译历史
- 持久化存储翻译记录
- 收藏常用翻译
- 历史搜索

## 能力声明（provides）

| 类型 | 名称 | 说明 | 优先级 |
|------|------|------|--------|
| tool | `translate_text` | 翻译文本（大模型） | 10 |
| tool | `translate_with_kb` | 小希翻译（知识库优先） | 15 |
| tool | `translate_detect` | 检测语言 | 10 |
| tool | `translate_history` | 翻译历史 | 10 |
| tool | `translate_favorites` | 收藏翻译 | 10 |

## 配置项

```json
{
  "defaultSourceLang": "auto",
  "defaultTargetLang": "zh-CN",
  "engine": "ollama",
  "maxHistory": 200,
  "assistantName": "小希"
}
```
