### 13.1.1 IPC Handler 注册机制 <!-- ✅ Issue#209: 已修复 -->

> **重要**：所有 IPC handler 必须在主进程启动时统一注册，渲染进程通过 `window.electronAPI.invoke()` 或 `window.electronAPI.on()` 调用。

#### 注册架构

IPC handler 采用**模块化注册**模式，每个功能域的 handlers 独立文件，由主进程入口统一加载：

```
src/main/
├── ipc/
│   ├── ai-handlers.ts       # AI 对话相关 handlers
│   ├── config-handlers.ts   # 配置管理 handlers
│   ├── module-handlers.ts   # 模块管理 handlers
│   └── index.ts             # 统一注册入口
└── index.ts                 # 主进程入口（调用 registerAllHandlers）
```

#### 注册流程

```typescript
// src/main/ipc/index.ts
import { registerAIHandlers } from './ai-handlers'
import { registerConfigHandlers } from './config-handlers'
import { registerModuleHandlers } from './module-handlers'
import type { AIService } from '../types/ai'

/**
 * 注册所有 IPC handlers
 * 在主进程 app.whenReady() 之后、创建窗口之前调用
 *
 * @param services 依赖注入的服务实例
 */
export function registerAllHandlers(services: { ai: AIService }): void {
  registerAIHandlers(services.ai)
  registerConfigHandlers()
  registerModuleHandlers()
  console.log('[IPC] 所有 handlers 注册完成')
}
```

#### Handler 注册规范

1. **使用 `ipcMain.handle()` 处理请求-响应模式**（异步，返回 Promise）：
   ```typescript
   ipcMain.handle('channel:name', async (_event, params) => {
     // 处理逻辑
     return result
   })
   ```

2. **使用 `ipcMain.on()` 处理事件推送模式**（无需返回值）：
   ```typescript
   ipcMain.on('channel:name', (_event, data) => {
     // 处理逻辑
   })
   ```

3. **流式通信采用事件式方案**（详见步骤 1 说明）：
   ```typescript
   ipcMain.handle('ai:chatStream', async (event, { requestId, messages }) => {
     const stream = ai.chatStream(messages)
     for await (const chunk of stream) {
       event.sender.send(`ai:chatStream:chunk:${requestId}`, chunk)
     }
     event.sender.send(`ai:chatStream:done:${requestId}`)
   })
   ```

4. **错误处理**：handler 内部必须 try-catch，避免未处理异常导致进程崩溃：
   ```typescript
   ipcMain.handle('channel:name', async (_event, params) => {
     try {
       return await doWork(params)
     } catch (err) {
       const message = err instanceof Error ? err.message : String(err)
       throw new Error(`[channel:name] ${message}`)
     }
   })
   ```

5. **生命周期**：
   - handlers 在 `app.whenReady()` 后、`BrowserWindow` 创建前注册
   - 窗口销毁后，相关 sender 自动失效（通过 `sender.isDestroyed()` 检查）
   - 应用退出时无需手动注销 handlers

#### 预加载脚本桥接

渲染进程通过预加载脚本暴露的 `electronAPI` 调用 IPC：

```typescript
// src/preload/index.ts
import { contextBridge, ipcRenderer } from 'electron'

contextBridge.exposeInMainWorld('electronAPI', {
  invoke: (channel: string, ...args: unknown[]) => ipcRenderer.invoke(channel, ...args),
  on: (channel: string, callback: (...args: unknown[]) => void) => {
    ipcRenderer.on(channel, (_event, ...args) => callback(...args))
    return () => ipcRenderer.removeAllListeners(channel)
  },
  send: (channel: string, ...args: unknown[]) => ipcRenderer.send(channel, ...args)
})
```

### 13.2 开发步骤

#### 步骤 1：实现对话服务

> **流式 IPC 设计说明**：Electron 的 `ipcRenderer.invoke()` 不支持回调式流式通信（函数无法跨 IPC 传递）。正确方案是事件式流式通信：
> - 渲染进程通过 `ipcRenderer.invoke('ai:chatStream', { requestId, messages })` 发起请求（invoke 确保 handler 注册后再推送）
> - 主进程通过 `event.sender.send('ai:chatStream:chunk:${requestId}', ...)` 逐块推送到特定请求
> - 主进程发送 `ai:chatStream:done:${requestId}` 或 `ai:chatStream:error:${requestId}` 结束特定流
> - `requestId` 由渲染进程生成（如 `crypto.randomUUID()`），确保多个并发流互不干扰

**src/renderer/src/services/chatService.ts**：

```typescript
import type { ChatMessage } from '../stores/useChatStore'

export interface StreamCallbacks {
  onChunk: (chunk: string) => void
  onToolCall: (
    name: string,
    result: unknown,
    meta?: {
      arguments?: Record<string, unknown>
      error?: string
      status?: 'running' | 'success' | 'error'
      durationMs?: number
    }
  ) => void
  onDone: (fullText: string) => void
  onError: (error: string) => void
}

export class ChatService {
  private static activeStream: { requestId: string; cleanup: () => void } | null = null

  /** 非流式发送消息 */
  static async sendMessage(
    content: string,
    history: ChatMessage[]
  ): Promise<{ response: string; toolCalls?: Array<{
    id: string
    name: string
    arguments?: Record<string, unknown>
    result?: unknown
    error?: string
    status?: 'running' | 'success' | 'error'
    durationMs?: number
  }> }> {
    const messages = history.map((m) => ({
      role: m.role,
      content: m.content,
      ...(m.images && m.images.length > 0 ? { images: m.images } : {})
    }))
    messages.push({ role: 'user' as const, content })

    const result = await window.electronAPI.invoke('ai:chat', { messages })
    return result as { response: string; toolCalls?: Array<{
      id: string
      name: string
      arguments?: Record<string, unknown>
      result?: unknown
      error?: string
      status?: 'running' | 'success' | 'error'
      durationMs?: number
    }> }
  }

  /** 流式发送消息（基于 requestId 事件监听，支持并发流） */
  static async sendMessageStream(
    content: string,
    history: ChatMessage[],
    callbacks: StreamCallbacks
  ): Promise<void> {
    // 清理上一次流
    this.activeStream?.cleanup()

    const messages = history.map((m) => ({
      role: m.role,
      content: m.content,
      ...(m.images && m.images.length > 0 ? { images: m.images } : {})
    }))
    messages.push({ role: 'user' as const, content })

    // 生成唯一 requestId，用于区分并发流
    const requestId = crypto.randomUUID()
    let fullText = ''
    // Issue#217: 防止 offError 事件监听和 invoke catch 重复调用 onError
    let errorHandled = false

    // 注册请求专属事件监听（channel 包含 requestId，避免并发干扰）
    const offChunk = window.electronAPI.on(`ai:chatStream:chunk:${requestId}`, (_event: unknown, chunk: {
      content?: string
      toolCall?: {
        name: string
        arguments?: Record<string, unknown>
        result?: unknown
        error?: string
        status?: 'running' | 'success' | 'error'
        durationMs?: number
      }
    }) => {
      if (chunk.content) {
        fullText += chunk.content
        callbacks.onChunk(chunk.content)
      }
      if (chunk.toolCall) {
        callbacks.onToolCall(chunk.toolCall.name, chunk.toolCall.result, {
          arguments: chunk.toolCall.arguments,
          error: chunk.toolCall.error,
          status: chunk.toolCall.status,
          durationMs: chunk.toolCall.durationMs
        })
      }
    })

    const offDone = window.electronAPI.on(`ai:chatStream:done:${requestId}`, () => {
      cleanup()
      callbacks.onDone(fullText)
    })

    const offError = window.electronAPI.on(`ai:chatStream:error:${requestId}`, (_event: unknown, data: { error: string }) => {
      if (errorHandled) return  // Issue#217: 防止与 invoke catch 重复调用 onError
      errorHandled = true
      cleanup()
      callbacks.onError(data.error)
    })

    const cleanup = () => {
      offChunk()
      offDone()
      offError()
      this.activeStream = null
    }

    this.activeStream = { requestId, cleanup }

    try {
      // invoke 确保主进程 handler 已注册，主进程通过 event.sender.send 推送 chunks
      await window.electronAPI.invoke('ai:chatStream', { requestId, messages })
    } catch (err) {
      if (!errorHandled) {
        errorHandled = true
        cleanup()
        callbacks.onError(err instanceof Error ? err.message : String(err))
      }
    }
  }

  /** 取消当前流 */
  static cancelStream(): void {
    this.activeStream?.cleanup()
    this.activeStream = null
  }
}
```

**主进程侧 IPC Handler 注册**（在版块 8 AI 调度器中实现）： <!-- ✅ Issue#206: 已修复 -->

```typescript
// src/main/ipc/ai-handlers.ts
import { ipcMain } from 'electron'
import type { AIService, ChatMessage, ChatOptions } from '../types/ai'

/**
 * 注册 AI 对话相关的 IPC handlers
 * 与版块 10 AIService 接口一致：
 *   - ai.chat(messages, options?) → ChatResponse
 *   - ai.chatStream(messages, options?) → AsyncGenerator<ChatChunk>
 *
 * 流式通信采用事件式方案（Electron invoke 不支持回调式流）：
 *   渲染进程 invoke('ai:chatStream', { requestId, messages, options }) 发起请求
 *   主进程通过 event.sender.send 将 chunks 推送回同一窗口
 *   channel 命名包含 requestId，确保并发流互不干扰
 */
export function registerAIHandlers(ai: AIService): void {
  // 非流式对话
  ipcMain.handle('ai:chat', async (_event, { messages }: { messages: ChatMessage[] }) => {
    try {
      return await ai.chat(messages)
    } catch (err) {
      const message = err instanceof Error ? err.message : String(err)
      throw new Error(`[ai:chat] ${message}`)
    }
  })

  // 流式对话（invoke handler，通过事件式推送 chunks）
  ipcMain.handle(
    'ai:chatStream',
    async (
      event,
      { requestId, messages, options }: {
        requestId: string
        messages: ChatMessage[]
        options?: ChatOptions
      }
    ) => {
      const sender = event.sender
      // 渲染进程已断开则直接返回
      if (sender.isDestroyed()) return

      try {
        const stream = ai.chatStream(messages, options)
        for await (const chunk of stream) {
          if (sender.isDestroyed()) return
          // 使用 requestId 专属 channel 推送，确保并发安全
          sender.send(`ai:chatStream:chunk:${requestId}`, chunk)
        }
        if (!sender.isDestroyed()) {
          sender.send(`ai:chatStream:done:${requestId}`)
        }
      } catch (err) {
        if (!sender.isDestroyed()) {
          sender.send(`ai:chatStream:error:${requestId}`, {
            error: err instanceof Error ? err.message : String(err)
          })
        }
      }
    }
  )
}
```

#### 步骤 1.5：自定义 Hook — useAutoScroll

> 提取自动滚动逻辑为独立 Hook，方便聊天组件复用，并支持"用户手动上翻时暂停自动滚动"等进阶行为。

**src/renderer/src/hooks/useAutoScroll.ts**：

```tsx
import { useRef, useEffect, useCallback } from 'react'

/**
 * useAutoScroll — 当依赖项变化时自动滚动到容器底部
 *
 * @param deps  触发滚动的依赖数组（如 messages、streamingContent）
 * @returns     ref 回调（挂载到滚动容器底部的哨兵元素） + 手动触发滚动的 scrollToBottom
 */
export function useAutoScroll(deps: unknown[]) {
  const endRef = useRef<HTMLDivElement>(null)
  const isUserScrolledUp = useRef(false)
  const containerRef = useRef<HTMLDivElement>(null)

  // 监听用户滚动：如果用户向上滚动超过 150px，暂停自动滚动
  const handleScroll = useCallback(() => {
    const el = containerRef.current
    if (!el) return
    const distanceFromBottom = el.scrollHeight - el.scrollTop - el.clientHeight
    isUserScrolledUp.current = distanceFromBottom > 150
  }, [])

  // 当 deps 变化且用户未手动上翻时，自动滚动到底部
  useEffect(() => {
    if (!isUserScrolledUp.current) {
      endRef.current?.scrollIntoView({ behavior: 'smooth' })
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, deps)

  const scrollToBottom = useCallback(() => {
    isUserScrolledUp.current = false
    endRef.current?.scrollIntoView({ behavior: 'smooth' })
  }, [])

  return { endRef, containerRef, handleScroll, scrollToBottom }
}
```

```tsx
import React, { useCallback } from 'react'
import { ErrorBoundary } from '../components/common/ErrorBoundary'
import { Loading } from '../components/common/Loading'
import { MessageList } from '../components/chat/MessageList'
import { ChatInput } from '../components/chat/ChatInput'
import { useAutoScroll } from '../hooks/useAutoScroll'
import {
  useChatStore,
  selectMessages,
  selectIsProcessing,
  selectStreamingContent,
  selectAddMessage,
  selectSetProcessing,
  selectAppendStreamingContent,
  selectSetStreamingContent,
  selectFlushStreamingBuffer
} from '../stores/useChatStore'
import { ChatService } from '../services/chatService'

/**
 * 聊天页面核心内容（独立于 ErrorBoundary，便于 hooks 正常使用）
 *
 * 加载状态策略：
 * - isProcessing=true 且尚无流式内容时 → 显示 Loading 指示器（"AI 正在思考…"）
 * - isProcessing=true 且已有流式内容时 → 隐藏 Loading，由 StreamingText 展示流式输出
 * - isProcessing=false → 正常显示消息列表
 *
 * 错误处理策略：
 * - 聊天服务层错误通过 onError 回调捕获，以系统消息形式展示在对话中
 * - 渲染层错误由外层 ErrorBoundary 捕获，展示降级 UI 而非白屏崩溃
 */
function ChatPageContent() {
  const messages = useChatStore(selectMessages)
  const isProcessing = useChatStore(selectIsProcessing)
  const streamingContent = useChatStore(selectStreamingContent)
  const addMessage = useChatStore(selectAddMessage)
  const setProcessing = useChatStore(selectSetProcessing)
  const appendStreamingContent = useChatStore(selectAppendStreamingContent)
  const setStreamingContent = useChatStore(selectSetStreamingContent)
  const flushStreamingBuffer = useChatStore(selectFlushStreamingBuffer)

  // 使用自定义 Hook 替代内联滚动逻辑
  const { endRef: messagesEndRef, containerRef, handleScroll, scrollToBottom } = useAutoScroll([messages, streamingContent])

  const handleSend = useCallback((content: string) => {
    if (!content.trim() || isProcessing) return

    addMessage({ role: 'user', content })
    setProcessing(true)
    setStreamingContent('')

    ChatService.sendMessageStream(content, messages, {
      onChunk: (chunk) => {
        appendStreamingContent(chunk)
      },
      onToolCall: (_name, _result) => {
        // 工具调用结果会包含在最终消息中
      },
      onDone: (fullText) => {
        // 流结束：先刷新缓冲区尾部内容，再添加完整消息
        flushStreamingBuffer()
        addMessage({ role: 'assistant', content: fullText })
        setStreamingContent('')  // ← Issue#205: 流结束后清空 streamingContent，防止 UI 重复显示
        setProcessing(false)
      },
      onError: (error) => {
        flushStreamingBuffer()
        addMessage({ role: 'system', content: `❌ 错误：${error}` })
        setStreamingContent('')  // ← Issue#205: 错误时同样清空
        setProcessing(false)
      }
    })
  }, [messages, isProcessing, addMessage, setProcessing, appendStreamingContent, setStreamingContent, flushStreamingBuffer])

  // 加载状态：仅在 AI 思考阶段（isProcessing 且尚无流式内容）显示 Loading
  const showLoading = isProcessing && !streamingContent

  return (
    <div className="chat-page">
      <MessageList
        messages={messages}
        streamingContent={streamingContent}
      />
      {showLoading && (
        <div className="chat-loading">
          <Loading size="sm" text="AI 正在思考…" />
        </div>
      )}
      <div ref={messagesEndRef} />
      <ChatInput
        onSend={handleSend}
        onPasteImage={(dataUrl) => {
          // 粘贴图片时，将其作为用户消息发送（包含 base64 图片数据）
          addMessage({ role: 'user', content: '[图片]', images: [dataUrl] })
        }}
        disabled={isProcessing}
      />
    </div>
  )
}

 * 聊天页面

 * - ErrorBoundary 捕获聊天区域的渲染异常，隔离错误不影响其他页面

          </button>
        </div>
      }
    >

  )
}

#### 步骤 3：实现消息列表组件 <!-- ✅ Issue#201: 已修复 --> <!-- ✅ Issue#218: 已修复 -->

> **Issue#218 规范 — 消息列表虚拟滚动**：消息列表必须使用虚拟滚动（Virtual Scrolling）以支持大量消息场景下的流畅渲染。推荐使用 `@tanstack/react-virtual`（轻量、无外部依赖）或 `react-window`。核心要求：
>
> 1. **动态行高**：消息气泡高度不固定，需使用 `measure` 机制动态计算每行高度
> 2. **自动滚动保持**：用户在底部附近时自动跟随新消息；用户上翻浏览历史时不打断
> 3. **流式内容兼容**：`streamingContent` 渲染区（当前正在生成的 AI 回复）不纳入虚拟列表，始终挂载在列表末尾，避免流式更新时反复触发 measure
> 4. **滚动锚定**：新消息到达且用户在底部附近时，`scrollToIndex` 到最后一条；用户手动上翻时（距底部 > 100px）不自动滚动
> 5. **性能阈值**：当消息数 ≤ 50 时可退化为普通 `messages.map()` 渲染（减少虚拟列表开销），超过阈值自动切换虚拟滚动

  messages: ChatMessage[]
  streamingContent: string

export function MessageList({ messages, streamingContent }: Props) {
  const listRef = useRef<HTMLDivElement>(null)
  const isNearBottom = useRef(true)
  const useVirtual = messages.length > VIRTUAL_SCROLL_THRESHOLD

  // 检测是否在底部附近

    const el = listRef.current
    if (!el) return
    isNearBottom.current = el.scrollHeight - el.scrollTop - el.clientHeight < 100

  const virtualizer = useVirtualizer({
    count: messages.length,
    getScrollElement: () => listRef.current,
    estimateSize: () => 80, // 预估每条消息高度，实际由 measure 动态调整
    overscan: 5,
  })

  // 自动滚动到底部（仅在用户已在底部附近时）
  useEffect(() => {
    if (isNearBottom.current) {
      if (useVirtual) {
        virtualizer.scrollToIndex(messages.length - 1, { align: 'end', behavior: 'smooth' })
      } else {
        listRef.current?.scrollTo({ top: listRef.current.scrollHeight, behavior: 'smooth' })
      }

    if (!useVirtual) {

        <MessageBubble key={msg.id} message={msg} />
      ))
    }

    const virtualItems = virtualizer.getVirtualItems()
    return (
      <div

          height: `${virtualizer.getTotalSize()}px`,
          width: '100%',
          position: 'relative',
        }}
      >

          const msg = messages[virtualRow.index]
          return (
            <div
              key={virtualRow.key}
              data-index={virtualRow.index}
              ref={(el) => {
                if (el) virtualizer.measureElement(el)
              }}
              style={{
                position: 'absolute',
                top: 0,
                left: 0,
                width: '100%',
                transform: `translateY(${virtualRow.start}px)`,
              }}
            >
              <MessageBubble message={msg} />
            </div>
          )
        })}
      </div>
    )
  }

  return (
    <div
      ref={listRef}
      className="message-list"
      onScroll={handleScroll}
      role="log"
      aria-label="对话消息列表"
      aria-live="polite"

**src/renderer/src/components/chat/markdown.tsx**（<!-- ✅ Issue#221: 已修复 --> 提取为共享 Markdown 工具模块，供 StreamingText 和 MessageBubble 共用）：

```tsx
import React from 'react'

// ─── 轻量 Markdown 解析器 ─────────────────────────────────────────────────────
// 仅支持：代码块（```）、行内代码（`）、粗体（**）、链接（[text](url)）、换行
// 供 StreamingText（流式渲染）和 MessageBubble（已完成消息渲染）共用

export interface MarkdownToken {
  type: 'text' | 'bold' | 'code-inline' | 'code-block' | 'link' | 'newline'
  content: string
  href?: string
  language?: string
}

/** 将文本解析为 Markdown token 数组 */
export function parseMarkdown(text: string): MarkdownToken[] {
  const tokens: MarkdownToken[] = []
  let remaining = text

  while (remaining.length > 0) {
    // 1. 代码块 ```lang\n...\n```
    const codeBlockMatch = remaining.match(/^```(\w*)\n?([\s\S]*?)```/)
    if (codeBlockMatch) {
      tokens.push({
        type: 'code-block',
        content: codeBlockMatch[2],
        language: codeBlockMatch[1] || undefined
      })
      remaining = remaining.slice(codeBlockMatch[0].length)
      continue
    }

    // 2. 行内代码 `...`
    const inlineCodeMatch = remaining.match(/^`([^`\n]+)`/)
    if (inlineCodeMatch) {
      tokens.push({ type: 'code-inline', content: inlineCodeMatch[1] })
      remaining = remaining.slice(inlineCodeMatch[0].length)
      continue
    }

    // 3. 粗体 **...**
    const boldMatch = remaining.match(/^\*\*([^*]+?)\*\*/)
    if (boldMatch) {
      tokens.push({ type: 'bold', content: boldMatch[1] })
      remaining = remaining.slice(boldMatch[0].length)
      continue
    }

    // 4. 链接 [text](url)
    const linkMatch = remaining.match(/^\[([^\]]+)\]\(([^)]+)\)/)
    if (linkMatch) {
      tokens.push({ type: 'link', content: linkMatch[1], href: linkMatch[2] })
      remaining = remaining.slice(linkMatch[0].length)
      continue
    }

    // 5. 换行
    if (remaining[0] === '\n') {
      tokens.push({ type: 'newline', content: '\n' })
      remaining = remaining.slice(1)
      continue
    }

    // 6. 普通文本（贪婪匹配直到下一个特殊字符）
    const textMatch = remaining.match(/^[^`*\[\n]+/)
    if (textMatch) {
      tokens.push({ type: 'text', content: textMatch[0] })
      remaining = remaining.slice(textMatch[0].length)
      continue
    }

    // 7. 无法匹配的单个字符（如孤立的 * 或 [），按普通文本处理
    tokens.push({ type: 'text', content: remaining[0] })
    remaining = remaining.slice(1)
  }

  return tokens
}

/** 将 token 数组渲染为 React 元素 */
export function renderTokens(tokens: MarkdownToken[]): React.ReactNode[] {
  return tokens.map((token, i) => {
    switch (token.type) {
      case 'bold':
        return <strong key={i}>{token.content}</strong>
      case 'code-inline':
        return <code key={i} className="inline-code">{token.content}</code>
      case 'code-block':
        return (
          <pre key={i} className="code-block">
            {token.language && (
              <div className="code-block-lang">{token.language}</div>
            )}
            <code>{token.content}</code>
          </pre>
        )
      case 'link':
        return (
          <a key={i} href={token.href} target="_blank" rel="noopener noreferrer">
            {token.content}
          </a>
        )
      case 'newline':
        return <br key={i} />
      default:
        return <span key={i}>{token.content}</span>
    }
  })
}

```tsx
import React, { useState, useEffect, useRef, useMemo, useCallback } from 'react'
import { parseMarkdown, renderTokens } from './markdown'

// ─── 类型定义 ───────────────────────────────────────────────────────────────

interface StreamingTextProps {
  /** 流式文本内容（每次追加新内容时传入完整文本） */
  content: string
  /** 每帧渲染的字符数（控制动画速度，默认 3） */
  charsPerFrame?: number
  /** 流式结束后的回调 */
  onStreamEnd?: () => void
  /** 是否启用 Markdown 渲染（默认 true） */
  markdown?: boolean
  /** 自定义 className */
  className?: string
}

// ─── 主组件 ──────────────────────────────────────────────────────────────────

export function StreamingText({
  content,
  charsPerFrame = 3,
  onStreamEnd,
  markdown = true,
  className = ''
}: StreamingTextProps) {
  const [displayedLength, setDisplayedLength] = useState(0)
  const [isStreaming, setIsStreaming] = useState(true)
  const [isTransitioning, setIsTransitioning] = useState(false)

  const rafRef = useRef<number>(0)
  const prevContentRef = useRef('')
  const displayedLengthRef = useRef(0)

  // 内容变化时：从上次停下的位置继续，而非重新开始
  useEffect(() => {
    // 新增内容到来，重置流式状态
    if (content !== prevContentRef.current) {
      prevContentRef.current = content
      setIsStreaming(true)
      setIsTransitioning(false)
    }
  }, [content])

  // requestAnimationFrame 驱动的逐字渲染
  useEffect(() => {
    if (!isStreaming) return

    const targetLength = content.length

    const animate = () => {
      const current = displayedLengthRef.current
      if (current >= targetLength) {
        // 流式渲染完成 → 触发过渡动画
        setIsStreaming(false)
        setIsTransitioning(true)
        setTimeout(() => {
          setIsTransitioning(false)
          onStreamEnd?.()
        }, 300) // 过渡动画持续 300ms
        return
      }

      // 自适应速度：内容越多，每帧渲染字符越多（保持流畅感）
      const dynamicCharsPerFrame = Math.max(
        charsPerFrame,
        Math.floor((targetLength - current) / 60) // 保证 ~1秒内追上
      )
      const nextLength = Math.min(current + dynamicCharsPerFrame, targetLength)

      displayedLengthRef.current = nextLength
      setDisplayedLength(nextLength)

      rafRef.current = requestAnimationFrame(animate)
    }

    rafRef.current = requestAnimationFrame(animate)
    return () => cancelAnimationFrame(rafRef.current)
  }, [content, isStreaming, charsPerFrame, onStreamEnd])

  // 渲染内容：根据 displayedLength 截取已渲染部分
  const renderedContent = useMemo(() => {
    const visibleText = content.slice(0, displayedLength)

    if (!markdown) {
      return <span className="streaming-plain">{visibleText}</span>
    }

    const tokens = parseMarkdown(visibleText)
    return <span className="streaming-markdown">{renderTokens(tokens)}</span>
  }, [content, displayedLength, markdown])

  // 判断是否为流式中（有内容且未完成）
  const showCursor = isStreaming && displayedLength > 0 && displayedLength < content.length

  return (
    <div
      className={`streaming-text ${isTransitioning ? 'streaming-text--transitioning' : ''} ${className}`}
      role="status"
      aria-live="polite"
      aria-label="AI 正在回复"
    >
      <div className="streaming-content">
        {renderedContent}
      </div>
      {showCursor && (
        <span className="streaming-cursor" aria-hidden="true">▊</span>
      )}
      {isTransitioning && (
        <span className="streaming-fade-overlay" aria-hidden="true" />
      )}
    </div>
  )
}

import React, { useCallback } from 'react'

import { showToast } from '../common/Toast'

interface Props {
  messageId: string
  role: 'user' | 'assistant' | 'system'
  content: string
}

export function MessageActions({ messageId, role, content }: Props) {
  const deleteMessage = useChatStore((s) => s.deleteMessage)
  const regenerateFrom = useChatStore((s) => s.regenerateFrom)

  const handleCopy = useCallback(async () => {
    try {
      await navigator.clipboard.writeText(content)
      showToast('已复制', { type: 'success' })
    } catch {
      showToast('复制失败', { type: 'error' })

    if (window.confirm('确定删除这条消息？')) {
      deleteMessage(messageId)
    }
  }, [messageId, deleteMessage])

  const handleRegenerate = useCallback(() => {
    regenerateFrom(messageId)
  }, [messageId, regenerateFrom])

  return (
    <div className="message-actions" role="toolbar" aria-label="消息操作">
      <button
        className="message-action-btn ghost sm"
        onClick={handleCopy}
        title="复制消息"
        aria-label="复制消息"
      >
        📋
      </button>
      <button
        className="message-action-btn ghost sm"
        onClick={handleDelete}
        title="删除消息"
        aria-label="删除消息"
      >
        🗑️
      </button>
      {role === 'assistant' && (
        <button
          className="message-action-btn ghost sm"
          onClick={handleRegenerate}
          title="重新生成"
          aria-label="重新生成"
        >
          🔄

**src/renderer/src/components/chat/ChatInput.tsx**：

```tsx
import React, { useState, useRef, useEffect, useCallback } from 'react'

interface Props {
  onSend: (content: string) => void
  /** 粘贴图片时的回调（base64 数据 URL） */
  onPasteImage?: (dataUrl: string) => void
  disabled?: boolean
}

/** 输入框最大字符数限制 */
const MAX_INPUT_LENGTH = 2000

export function ChatInput({ onSend, onPasteImage, disabled }: Props) {
  const [value, setValue] = useState('')
  const textareaRef = useRef<HTMLTextAreaElement>(null)

  // 自动调整高度
  useEffect(() => {
    const textarea = textareaRef.current
    if (textarea) {
      textarea.style.height = 'auto'
      textarea.style.height = `${Math.min(textarea.scrollHeight, 150)}px`
    }
  }, [value])

  const handleSubmit = () => {
    if (!value.trim() || disabled) return
    onSend(value.trim())
    setValue('')
  }

  const handleKeyDown = (e: React.KeyboardEvent) => {
    if (e.key === 'Enter' && !e.shiftKey) {
      e.preventDefault()
      handleSubmit()
    }
  }

  /**
   * 粘贴事件处理
   * - 图片：从剪贴板读取图片数据，转为 base64 后通过 onPasteImage 回调传递
   * - 多行文本：将连续换行合并为空格（单行输入场景），保留段落间空格
   * - 普通文本：按默认行为粘贴
   */
  const handlePaste = useCallback(
    (e: React.ClipboardEvent<HTMLTextAreaElement>) => {
      const clipboardData = e.clipboardData
      if (!clipboardData) return

      // 1. 处理粘贴的图片
      const imageItems = Array.from(clipboardData.items).filter((item) =>
        item.type.startsWith('image/')
      )
      if (imageItems.length > 0) {
        e.preventDefault()
        for (const item of imageItems) {
          const file = item.getAsFile()
          if (!file) continue
          const reader = new FileReader()
          reader.onload = () => {
            const dataUrl = reader.result as string
            onPasteImage?.(dataUrl)
          }
          reader.readAsDataURL(file)
        }
        return
      }

      // 2. 处理粘贴的多行文本：将换行符替换为空格，保持单行输入
      //    如果用户粘贴的是代码或多行内容，压缩为单行以便在输入框中显示
      const pastedText = clipboardData.getData('text/plain')
      if (pastedText && pastedText.includes('\n')) {
        e.preventDefault()
        // 将多行文本合并为单行：连续换行替换为单个空格，行首行尾空格清理
        const singleLine = pastedText
          .split('\n')
          .map((line) => line.trim())
          .filter((line) => line.length > 0)
          .join(' ')
        // 插入合并后的文本到当前光标位置
        const textarea = textareaRef.current
        if (textarea) {
          const start = textarea.selectionStart
          const end = textarea.selectionEnd
          const newValue = value.slice(0, start) + singleLine + value.slice(end)
          // 限制最大字符数
          const capped = newValue.slice(0, MAX_INPUT_LENGTH)
          setValue(capped)
          // 设置光标到插入文本之后
          requestAnimationFrame(() => {
            const cursorPos = Math.min(start + singleLine.length, MAX_INPUT_LENGTH)
            textarea.setSelectionRange(cursorPos, cursorPos)
          })
        }
        return
      }

      // 3. 普通单行文本：使用默认粘贴行为
    },
    [value, onPasteImage]
  )

  const charCount = value.length
  const isNearLimit = charCount > MAX_INPUT_LENGTH * 0.9
  const isOverLimit = charCount > MAX_INPUT_LENGTH

  return (
    <div className="chat-input-container">
      <textarea
        ref={textareaRef}
        className="chat-input"
        value={value}
        onChange={(e) => setValue(e.target.value)}
        onKeyDown={handleKeyDown}
        onPaste={handlePaste}
        placeholder={disabled ? '正在思考中...' : '输入消息... (Enter 发送，Shift+Enter 换行，支持粘贴图片)'}
        disabled={disabled}
        rows={1}
        maxLength={MAX_INPUT_LENGTH}
        aria-label="输入消息"
        aria-describedby="input-char-count"
      />
      <span
        id="input-char-count"
        className={`char-count ${isNearLimit ? 'char-count--warn' : ''} ${isOverLimit ? 'char-count--error' : ''}`}
        aria-live="polite"
      >
        {charCount}/{MAX_INPUT_LENGTH}
      </span>
      <button
        className="send-button"
        onClick={handleSubmit}
        disabled={disabled || !value.trim() || isOverLimit}
      >
        发送
      </button>
    </div>
  )
}
```

### 13.3 代码规范 <!-- ✅ Issue#210: 已修复 -->

- **消息渲染**：区分用户/助手/系统消息样式；助手消息通过共享 `markdown.tsx` 工具模块渲染 Markdown（代码块、行内代码、粗体、链接、换行），用户消息保持纯文本 <!-- ✅ Issue#221: 已修复 -->
- **流式输出**：使用 `appendStreamingContent` 逐步追加，避免闪烁
- **自动滚动**：新消息到达时自动滚动到底部
- **输入处理**：Enter 发送，Shift+Enter 换行
- **输入长度限制**：聊天输入框设置 `maxLength={2000}`，含实时字符计数显示（接近上限黄色警告、超出红色错误），超出限制时发送按钮自动禁用
- **历史管理**：保留最近 N 轮对话，老对话自动摘要
- **错误边界**：ChatPage 使用 `ErrorBoundary` 包裹，捕获聊天组件渲染异常，展示降级 UI 而非白屏崩溃；与 App 级 ErrorBoundary 形成双重保护
- **加载状态**：AI 思考阶段（`isProcessing` 且无流式内容时）显示 `<Loading>` 指示器；流式内容出现后自动隐藏 Loading，由 `StreamingText` 接管展示
- **消息分页/懒加载**：消息列表应采用分页或懒加载机制，避免大量消息一次性渲染导致性能问题
- **无障碍（Accessibility）**：聊天组件必须支持无障碍访问，确保屏幕阅读器用户和键盘用户可正常使用 <!-- ✅ Issue#213: 已修复 -->
