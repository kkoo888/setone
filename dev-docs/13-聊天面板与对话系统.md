### 13.2 组件说明

#### 13.2.1 ChatInput — 输入框组件

**文件**：`src/renderer/src/components/chat/ChatInput.tsx`

**Props 接口**：
```typescript
interface Props {
  onSend: (content: string) => void
  onStop?: () => void           // AI 回复中点击停止
  onPasteImage?: (dataUrl: string) => void  // 粘贴图片回调
  onAttachFile?: (name: string, content: string) => void  // 附件文件回调
  disabled?: boolean
}
```

**核心功能**：
- **自适应高度**：textarea 根据内容自动调整高度，最大 150px
- **字符限制**：`maxLength=2000`，实时显示字符计数（`charCount/2000`），接近上限黄色警告、超出红色错误
- **粘贴处理**：
  - 图片：从剪贴板读取图片转为 base64 Data URL，通过 `onPasteImage` 回调传递
  - 多行文本：自动合并为单行（换行符替换为空格）
- **附件按钮**：点击触发 `files:openPicker` IPC 调用，选择文件后通过 `onAttachFile` 回调
- **键盘交互**：Enter 发送，Shift+Enter 换行
- **发送/停止切换**：`disabled=true` 时显示停止图标（方形），点击调用 `onStop`；否则显示发送图标（纸飞机）
- **助手名称**：从 `useSettingsStore` 读取 `assistantName`，用于 placeholder 显示

#### 13.2.2 MessageList — 消息列表

**文件**：`src/renderer/src/components/chat/MessageList.tsx`

**Props 接口**：
```typescript
interface Props {
  messages: ChatMessage[]
  streamingContent: string
  containerRef?: React.RefObject<HTMLDivElement | null>
  endRef?: React.RefObject<HTMLDivElement | null>
  onScroll?: () => void
}
```

**核心功能**：
- **空状态引导**：无消息时显示 "开始和我聊天吧！" 引导文案
- **消息渲染**：遍历 `messages` 数组，每条消息渲染为 `MessageBubble`
- **流式输出**：`streamingContent` 非空时，在列表末尾渲染 `StreamingText` 组件，带头像和弹跳动画
- **头像**：优先使用 `useSettingsStore` 中的自定义头像，否则使用默认 🌸 emoji
- **无障碍**：容器设置 `role="log"` `aria-label="对话消息列表"` `aria-live="polite"`

#### 13.2.3 MessageBubble — 消息气泡

**文件**：`src/renderer/src/components/chat/MessageBubble.tsx`

**核心功能**：
- **角色区分**：用户消息（右侧紫色）、助手消息（左侧灰色）、系统消息（居中黄色）
- **Markdown 渲染**：助手和系统消息使用 `parseMarkdown` + `renderTokens` 渲染，用户消息保持纯文本
- **情绪动画**：
  - 错误消息：头像抖动动画（`avatar-emotion--shake`）
  - 工具调用执行中：头像脉冲动画（`avatar-emotion--pulse`）
- **工具调用**：`message.toolCalls` 非空时，渲染 `ToolCallCard` 列表
- **消息操作**：每条消息右上角显示 `MessageActions` 操作菜单（hover 显示）
- **时间显示**：使用 `Intl.DateTimeFormat().resolvedOptions().timeZone` 获取用户本地时区
- **系统消息图标**：使用 `SettingOne` 图标组件

#### 13.2.4 MessageActions — 消息操作

#### 13.2.5 StreamingText — 流式文本渲染

**文件**：`src/renderer/src/components/chat/StreamingText.tsx`

**核心机制**：
- **requestAnimationFrame 逐字渲染**：通过 `displayedLength` 控制可见字符数，每帧增加 `dynamicCharsPerFrame` 个字符
- **自适应速度**：`Math.max(charsPerFrame, Math.floor((targetLength - current) / 60))`，保证约 1 秒追上
- **Markdown 实时渲染**：使用 `parseMarkdown` 解析已显示部分，支持代码块、行内代码、粗体、链接
- **光标动画**：流式中显示闪烁光标 `▊`，结束时 300ms 过渡动画
- **助手名称**：从 `useSettingsStore` 读取，用于 `aria-label`

**Props**：
```typescript
interface StreamingTextProps {
  content: string
  charsPerFrame?: number     // 默认 3
  onStreamEnd?: () => void
  markdown?: boolean         // 默认 true
  className?: string
}
```

#### 13.2.6 markdown — 轻量 Markdown 解析器

**文件**：`src/renderer/src/components/chat/markdown.tsx`

**支持的语法**：
| 语法 | Token 类型 | 示例 |
|------|-----------|------|
| 代码块 | `code-block` | ` ```lang\ncode\n``` ` |
| 行内代码 | `code-inline` | `` `code` `` |
| 粗体 | `bold` | `**text**` |
| 链接 | `link` | `[text](url)` |
| 换行 | `newline` | `\n` |
| 普通文本 | `text` | 其他内容 |

**导出函数**：
- `parseMarkdown(text: string): MarkdownToken[]` — 解析文本为 token 数组
- `renderTokens(tokens: MarkdownToken[]): React.ReactNode[]` — 渲染 token 为 React 元素

### 13.3 IPC 通信

#### 13.3.1 流式通信方案

采用**事件式流式通信**（Electron `invoke` 不支持回调式流）：

1. 渲染进程通过 `ipcRenderer.invoke('ai:chatStream', { requestId, messages })` 发起请求
2. 主进程通过 `event.sender.send('ai:chatStream:chunk:${requestId}', ...)` 逐块推送
3. 主进程发送 `ai:chatStream:done:${requestId}` 或 `ai:chatStream:error:${requestId}` 结束流
4. `requestId` 由渲染进程生成（`crypto.randomUUID()`），确保并发流互不干扰

#### 13.3.2 AI 对话 IPC Handler

**文件**：`src/main/ipc-handlers/ai.handlers.ts`

**注册的通道**：
- `ai:chat` — 非流式对话（支持工具调用循环，最多 5 轮）
- `ai:chatStream` — 流式对话（支持工具调用循环，最多 5 轮）

**工具调用流程**：
1. `collectModuleTools(deps)` — 从所有活跃模块收集工具定义，转换为 Ollama ToolDefinition 格式
2. LLM 返回 `tool_calls` → `executeToolCall()` 遍历模块查找匹配能力并执行
3. 工具结果作为 `tool` role 消息加入历史，再次请求 LLM
4. 最多循环 5 轮，防止无限循环

**工具过滤规则**：
- 跳过 `skill_` 前缀的内部工具（除白名单外）
- 跳过元工具：`tool_register`、`tool_execute`、`tool_list`、`tool_route`
