### 19.3 核心服务

#### 19.3.1 VisionManager（vision-manager.ts）

视觉管理器，整合了屏幕捕获、帧变化检测和 AI 画面分析功能。

**接口定义**：

```typescript
interface VisionFrame {
  imageUrl: string           // 帧的 Data URL
  timestamp: number          // 时间戳
  changed: boolean           // 是否有变化
  analysis?: string          // AI 分析结果（可选）
  changeHash?: string        // 帧的 SHA-256 哈希
  changeDescription?: string // 变化描述
}

type AnalysisMode = 'general' | 'text' | 'code'
```

**构造参数**：

```typescript
constructor(logger: Logger, settings?: {
  defaultFps?: number       // 默认帧率，默认 1
  ollamaBaseUrl?: string    // Ollama 服务地址，默认 'http://localhost:11434'
  visionModel?: string      // 视觉模型名称，默认 'qwen2.5-vl'
})
```

**方法**：

| 方法 | 说明 | 参数 | 返回值 |
|------|------|------|--------|
| `setEventBus(eventBus)` | 绑定事件总线 | `ScopedEventBus` | `void` |
| `startCapture(fps, onFrame)` | 开始连续捕获 | 帧率 + 回调函数 | `void` |
| `stopCapture()` | 停止捕获 | 无 | `void` |
| `analyze(mode?)` | 单次 AI 分析当前画面 | 分析模式 | `Promise<VisionFrame>` |
| `isActive()` | 是否正在捕获 | 无 | `boolean` |
| `getFps()` | 获取当前帧率 | 无 | `number` |
| `setFps(fps)` | 设置帧率 | 帧率值 | `void` |

### 19.4 帧变化检测

使用 **SHA-256 哈希** 进行帧变化检测：

```
帧数据 → createHash('sha256').update(data).digest('hex') → 当前帧哈希
当前帧哈希 !== 上一帧哈希 → changed = true
```

- 捕获分辨率：640×360（连续捕获用，降低性能开销）
- 分析分辨率：1280×720（单次分析用，保证识别质量）
- 哈希算法：SHA-256（Node.js `crypto` 模块）
- 变化时通过 `eventBus.emit('vision:frame-changed', ...)` 发送事件

### 19.5 AI 画面分析

调用 Ollama 视觉模型进行画面分析，支持三种模式：

| 模式 | 用途 | Prompt |
|------|------|--------|
| `general` | 通用描述 | "请详细描述这张屏幕截图中的内容..." |
| `text` | 文字识别 | "请识别图片中的所有文字，按原始布局输出..." |
| `code` | 代码识别 | "请识别图片中的代码片段..." |

**实现细节**：
- 通过 `desktopCapturer` 截取屏幕（1280×720）
- 提取 base64 数据，调用 Ollama `/api/chat` 接口
- 60 秒超时保护（AbortController）
- 分析失败时返回错误描述而非抛出异常

### 19.6 模块入口（index.ts）

`VisionModule` 实现 `Module` 接口，激活时创建 `VisionManager` 实例并绑定事件总线。

**提供的工具能力**：

| 工具名 | 说明 | 参数 | 返回值 |
|--------|------|------|--------|
| `vision_start` | 开始视觉捕获 | `{ fps?: number }` | `{ capturing: true, fps: number }` |
| `vision_stop` | 停止视觉捕获 | 无 | `{ capturing: false }` |
| `vision_analyze` | AI 分析当前画面 | `{ mode?: 'general'\|'text'\|'code' }` | `VisionFrame` |

**事件**：
- `vision:frame`：每帧捕获时触发（通过 `onFrame` 回调）
- `vision:frame-changed`：画面变化时触发（通过 eventBus）

**配置项**（通过 `context.config.settings` 传入）：
- `defaultFps`：默认帧率（默认 1）
- `ollamaBaseUrl`：Ollama 服务地址
- `visionModel`：视觉模型名称

### 19.8 代码规范

- **变化检测**：SHA-256 哈希比较，高效且避免存储整帧数据
- **帧率控制**：fps 范围 0.5~30，通过 `setInterval` 实现定时捕获
- **AI 分析**：调用 Ollama 视觉模型（qwen2.5-vl），支持三种分析模式
- **事件驱动**：通过 `ScopedEventBus` 发送帧变化事件，与模块系统解耦
- **停用清理**：`deactivate()` 时停止捕获
