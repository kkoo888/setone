### 17.3 核心服务

#### 17.3.1 ScreenCaptureService（screen-capture.ts）

屏幕截图服务，使用 Electron `desktopCapturer` API 捕获屏幕。

**接口定义**：

```typescript
interface CaptureResult {
  imageUrl: string    // Data URL（data:image/png;base64,...）
  width: number
  height: number
  timestamp: number
}

interface CaptureRegion {
  x: number
  y: number
  width: number
  height: number
}
```

**方法**：

| 方法 | 说明 | 参数 | 返回值 |
|------|------|------|--------|
| `captureScreen()` | 截取全屏 | 无 | `Promise<CaptureResult>` |
| `captureRegion(region)` | 截取指定区域 | `CaptureRegion` | `Promise<CaptureResult>` |

**实现细节**：
- 通过 `desktopCapturer.getSources()` 获取屏幕源，缩略图尺寸 1920×1080
- `captureScreen()` 返回 `source.thumbnail.toDataURL()` 格式的图片
- `captureRegion()` 先截取全屏，再通过 canvas 裁剪指定区域（渲染进程侧处理）
- 截图失败时抛出异常并记录错误日志

#### 17.3.2 OcrService（ocr.ts）

OCR 文字识别服务，调用 Ollama 视觉模型（qwen2.5-vl）进行文字识别。

**接口定义**：

```typescript
interface OcrResult {
  text: string
  confidence: number
  regions: Array<{ text: string; x: number; y: number; width: number; height: number }>
}
```

**构造参数**：

```typescript
constructor(logger: Logger, options?: {
  ollamaBaseUrl?: string   // 默认 'http://localhost:11434'
  visionModel?: string     // 默认 'qwen2.5-vl'
})
```

**方法**：

| 方法 | 说明 | 参数 | 返回值 |
|------|------|------|--------|
| `recognize(imageDataUrl)` | 从图片 Data URL 识别文字 | 图片 Data URL | `Promise<OcrResult>` |
| `recognizeScreen()` | 从屏幕截图识别文字 | 无 | `Promise<OcrResult>` |
| `recognizeBatch(imageDataUrls)` | 批量 OCR 识别 | Data URL 数组 | `Promise<OcrResult[]>` |

**实现细节**：
- 从 Data URL 中提取 base64 数据，调用 Ollama `/api/chat` 接口
- 使用 `qwen2.5-vl` 视觉模型，prompt 为"请识别图片中的所有文字，按原始布局输出"
- 60 秒超时保护（AbortController）
- `recognizeScreen()` 内部创建 `ScreenCaptureService` 实例，先截图再识别
- `recognizeBatch()` 串行处理多张图片
- 置信度估算：基于文本长度、中英文字符、数字等特征计算（0~0.95）
- 区域解析：按行拆分文本，估算每行位置（行高 24px，字符宽 12px）
- 识别失败时返回空结果 `{ text: '', confidence: 0, regions: [] }`

### 17.4 模块入口（index.ts）

`ScreenModule` 实现 `Module` 接口，激活时创建 `ScreenCaptureService` 和 `OcrService` 实例。

**提供的工具能力**：

| 工具名 | 说明 | 参数 | 返回值 |
|--------|------|------|--------|
| `screen_capture` | 截取屏幕 | 无 | `CaptureResult` |
| `screen_ocr` | OCR 文字识别 | `{ imageUrl?: string }` | `OcrResult` |
| `screen_ocr_batch` | 批量 OCR 识别 | `{ imageUrls: string[] }` | `OcrResult[]` |

**配置项**（通过 `context.config.settings` 传入）：

- `ollamaBaseUrl`：Ollama 服务地址（默认 `http://localhost:11434`）
- `visionModel`：视觉模型名称（默认 `qwen2.5-vl`）

### 17.6 代码规范

- **截图方式**：使用 Electron `desktopCapturer` API，需在主进程中调用
- **OCR 引擎**：调用 Ollama 视觉模型（qwen2.5-vl），非本地 tesseract.js
- **返回格式**：截图结果为 Data URL（`data:image/png;base64,...`）
- **错误处理**：截图和 OCR 失败时均记录日志，OCR 失败返回空结果
