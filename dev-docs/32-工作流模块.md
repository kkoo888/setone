## 核心架构

### WorkflowEngine
工作流执行引擎，负责编排和执行完整工作流：
- `execute(workflow, overrides)` — 执行工作流，返回运行记录
- 管理运行状态（running/paused/completed/failed/aborted）
- 支持超时控制（默认 300s）
- 支持暂停/恢复/中止

### StepExecutor
步骤执行器，执行工作流中的单个步骤：
- `refreshCapabilities()` — 刷新能力注册表
- 支持工具调用、事件触发、条件判断等步骤类型
- 执行上下文传递

### WorkflowScheduler
定时调度器，基于 Cron 表达式：
- Cron 表达式解析和匹配
- 定时触发工作流执行

### WorkflowStore / Repositories
持久化层：
- 工作流定义 CRUD（SQLite）
- 运行记录存储和查询

| 类型 | 名称 | 说明 |

| tool | `workflow_pause` | 暂停执行中的工作流 |
