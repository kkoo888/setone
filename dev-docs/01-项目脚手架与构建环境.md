## 版块 1：项目脚手架 & 构建环境搭建

```

│   ├── preload/                      # 预加载脚本
│   │   └── index.ts                  # contextBridge 暴露 API
│   └── renderer/                     # 渲染进程（React 应用）
│       ├── index.html                # HTML 入口
```

> 📌 创建上述目录骨架：
> ```bash
> mkdir -p src/main/{ipc,utils,types} src/preload src/renderer/src/{components,pages,services,stores,styles}
> mkdir -p src/shared/types modules resources tests/{unit,integration,e2e} scripts docs
> ```

#### 步骤 4：编写主进程入口

**src/main/index.ts**：

```typescript
import { app, BrowserWindow } from 'electron'
import { join } from 'path'

let mainWindow: BrowserWindow | null = null

function createWindow(): void {
  mainWindow = new BrowserWindow({
    width: 1200,
    height: 800,
    minWidth: 800,
    minHeight: 600,
    webPreferences: {
      preload: join(__dirname, '../preload/index.js'),
      contextIsolation: true,
      nodeIntegration: false,
      // ⚠️ sandbox: false 是因为 preload 脚本需要直接访问 Node.js API
      // （如 fs、path、child_process）来支持模块加载、日志等功能。
      // 生产环境中 preload 脚本应严格控制暴露给渲染进程的 API 范围。
      // 如果模块不需要 Node.js 能力，建议改回 sandbox: true 以增强安全性。
      sandbox: false
    },
    titleBarStyle: 'hiddenInset',
    show: false
  })

  // 开发环境加载 Vite dev server，生产环境加载打包文件
  if (process.env.ELECTRON_RENDERER_URL) {
    mainWindow.loadURL(process.env.ELECTRON_RENDERER_URL)
  } else {
    mainWindow.loadFile(join(__dirname, '../renderer/index.html'))
  }

  mainWindow.once('ready-to-show', () => {
    mainWindow.show()
  })

  mainWindow.on('closed', () => {
    mainWindow = null
  })
}

app.whenReady().then(() => {
  createWindow()

  app.on('activate', () => {
    if (BrowserWindow.getAllWindows().length === 0) {
      createWindow()
    }
  })
})

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') {
    app.quit()
  }
})
```

#### 步骤 5：编写预加载脚本

**src/preload/index.ts**：

```typescript
import { contextBridge, ipcRenderer } from 'electron'

// 暴露给渲染进程的安全 API
contextBridge.exposeInMainWorld('electronAPI', {
  // 平台信息
  platform: process.platform,

  // IPC 通信（双向）
  invoke: (channel: string, ...args: unknown[]) => ipcRenderer.invoke(channel, ...args),
  send: (channel: string, ...args: unknown[]) => ipcRenderer.send(channel, ...args),
  on: (channel: string, callback: (...args: unknown[]) => void) => {
    const listener = (_event: Electron.IpcRendererEvent, ...args: unknown[]) => callback(...args)
    ipcRenderer.on(channel, listener)
    // 仅移除本次注册的监听器，避免误删其他监听器
    return () => ipcRenderer.removeListener(channel, listener)
  }
})
```

### 1.3 代码规范

- **文件命名**：主进程 `camelCase.ts`，组件 `PascalCase.tsx`，工具函数 `camelCase.ts`
- **导入顺序**：`electron` → 第三方库 → 内部模块 → 相对路径 → 样式文件
- **缩进**：2 空格，不使用 Tab
- **引号**：单引号，JSX 中双引号
- **分号**：不加分号
- **组件导出**：默认导出 `export default function ComponentName()`
