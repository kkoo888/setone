# 图标与状态消息开发规范

> **适用范围**：所有 `src/renderer/` 下的页面和组件  
> **生效日期**：2026-05-21  
> **说明**：统一图标、状态消息、空状态的使用方式，避免散落各处导致不一致

---

## 一、核心原则

**所有图标和状态消息统一定义在 `src/renderer/src/utils/statusMessages.ts`，禁止各页面自行定义或直接从 `@icon-park/react` 引入状态/空状态/操作类图标。**

---

## 二、文件结构

```
src/renderer/src/
├── utils/
│   └── statusMessages.ts      ← 唯一图标+消息源
├── components/
│   └── common/
│       └── IconMap.tsx         ← 兼容层（re-export from statusMessages）
```

### statusMessages.ts 导出一览

| 导出名 | 类型 | 用途 |
|--------|------|------|
| `SIDEBAR_ICONS` | `Record<string, ReactNode>` | 侧边栏页面图标 |
| `MODULE_PAGE_ICONS` | `Record<string, ReactNode>` | 模块占位页图标 |
| `STATUS_ICONS` | `{ loading, success, error, warning, info }` | 行内状态图标（size=14） |
| `THEME_ICONS` | `Record<string, ReactNode>` | 主题切换图标 |
| `ACTION_ICONS` | `Record<string, ReactNode>` | 通用操作图标 |
| `EMPTY_ICONS` | `Record<string, ReactNode>` | 空状态图标（size=32） |
| `StatusEmoji` | `{ success, error, warning, info, loading }` | Emoji 文本常量 |
| `Msg` | `Record<string, string \| Function>` | 通用操作结果消息 |

## 三、使用规范

### 3.1 状态消息（setMessage）

**场景**：页面中通过 `setMessage()` 显示操作结果、错误提示等。

**规范**：使用 `Msg.*` 获取标准化的 emoji 字符串。

```tsx
import { Msg } from '../../utils/statusMessages'

// ✅ 正确
setMessage(Msg.offline)
setMessage(Msg.downloadComplete('config.json'))
setMessage(Msg.importSuccess(3, 1))
setMessage(Msg.loadFailed('网络超时'))

// ❌ 禁止
setMessage(STATUS_ICONS.success + ' 下载完成')        // React 对象拼字符串 → [object Object]
setMessage('STATUS_ICONS.warning + ' 断网...')        // 引号不匹配，语法错误
setMessage('✅ 自己写的文案')                          // 不统一，改文案要到处找
```

### 3.2 JSX 模板中的状态图标

**场景**：在 JSX 中展示行内状态图标（如下载状态、执行结果）。

**规范**：使用 `{STATUS_ICONS.*}`，必须包裹在 JSX 表达式 `{}` 中。

```tsx
import { STATUS_ICONS } from '../../utils/statusMessages'

// ✅ 正确
<span>{STATUS_ICONS.success} 已完成</span>
<span>{STATUS_ICONS.loading} 准备中...</span>
{isDownloading ? <>{STATUS_ICONS.loading} 下载中...</> : <>{downloadIcon} 下载</>}

// ❌ 禁止
<span>STATUS_ICONS.success + ' 已完成</span>          // 字符串拼接，不渲染图标
<span>{STATUS_ICONS.success} + ' 已完成'</span>       // 对象拼字符串
```

### 3.3 空状态图标（ModuleList emptyIcon）

**场景**：`<ModuleList>` 组件的 `emptyIcon` 属性。

**规范**：使用 `EMPTY_ICONS.*`。

```tsx
import { EMPTY_ICONS } from '../../utils/statusMessages'

// ✅ 正确
<ModuleList emptyText="暂无文档" emptyIcon={EMPTY_ICONS.book}>
<ModuleList emptyText="暂无通知" emptyIcon={EMPTY_ICONS.bell}>

// ❌ 禁止
<ModuleList emptyText="暂无文档" emptyIcon={<Inbox size={32} />}>  // 内联定义，不统一
```

### 3.4 新增图标/消息

需要新增图标或消息时，**只修改 `statusMessages.ts`**，然后在页面中引用：

```tsx
// 1. 在 statusMessages.ts 中添加
export const Msg = {
  // ...已有消息
  newFeatureSuccess: '✅ 新功能操作成功',
  newFeatureFailed: (reason: string) => `❌ 新功能失败：${reason}`,
}

// 2. 在页面中使用
import { Msg } from '../../utils/statusMessages'
setMessage(Msg.newFeatureSuccess)
```

## 四、迁移检查清单

将现有页面迁移到本规范时，按以下清单逐项检查：

- [ ] 移除 `from '@icon-park/react'` 中的状态/空状态/操作类图标导入
- [ ] 移除页面内联的 `STATUS_ICONS.*`、`EMPTY_ICONS.*` 定义
- [ ] `setMessage()` 中的字符串拼接替换为 `Msg.*`
- [ ] JSX 模板中的 `STATUS_ICONS.*` 确保包裹在 `{}` 中
- [ ] 保留合理的 `@icon-park/react` 直接导入：仅限页面特有的业务图标（如 `BookOpen`、`Search`）
