> **前置依赖**：无
> **版块**：36
> **说明**：全局快捷命令面板，Ctrl+K 呼出，模糊搜索快速执行

## 能力声明（provides）

| 类型 | 名称 | 说明 |
|------|------|------|
| tool | `palette_open` | 打开命令面板 |
| tool | `palette_close` | 关闭命令面板 |
| tool | `palette_register_command` | 注册自定义命令 |
| tool | `palette_search` | 搜索命令 |
| tool | `palette_list_commands` | 列出所有命令 |

## 消费事件

| 事件 | 说明 |
|------|------|
| `palette:open` | 打开面板 |
| `palette:close` | 关闭面板 |
