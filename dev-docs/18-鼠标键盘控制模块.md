### 18.3 核心服务

#### 18.3.1 MouseService（mouse.ts）

鼠标控制服务，支持 Windows/macOS/Linux 三平台。优先使用 robotjs（如果已安装），否则降级到系统命令。

**接口定义**：

```typescript
interface Position { x: number; y: number }
```

**驱动策略**：

| 优先级 | 驱动 | 说明 |
|--------|------|------|
| 1 | robotjs | 通过 `createRequire` 动态加载，安装则使用 |
| 2 | 系统命令 | 未安装 robotjs 时降级 |

**系统命令实现**：

| 平台 | 移动 | 点击 | 获取位置 |
|------|------|------|----------|
| Linux | `xdotool mousemove` | `xdotool click` | `xdotool getmouselocation` |
| macOS | `osascript` | `osascript` | `osascript` |
| Windows | PowerShell `[System.Windows.Forms.Cursor]::Position` | PowerShell SendKeys | PowerShell |

**方法**：

| 方法 | 说明 | 参数 |
|------|------|------|
| `getPosition()` | 获取当前鼠标坐标 | 无 |
| `move(x, y)` | 移动鼠标到指定位置 | X、Y 坐标 |
| `click(x, y, button?)` | 点击鼠标 | 坐标 + 按键（left/right/middle，默认 left） |
| `doubleClick(x, y)` | 双击鼠标 | X、Y 坐标 |
| `drag(from, to)` | 拖拽鼠标 | 起始位置 → 目标位置 |
| `scroll(amount)` | 鼠标滚轮 | 正数向上，负数向下 |

**实现细节**：
- robotjs 模式：直接调用 `robot.moveMouse()`、`robot.mouseClick()` 等原生方法
- 系统命令模式：通过 `execSync()` 执行，超时 5000ms
- 拖拽实现：robotjs 使用 `mouseToggle('down')` → `moveMouse()` → `mouseToggle('up')`；系统命令模式各平台独立实现
- 滚动实现：Linux 用 `xdotool click 4/5`，macOS 用 `osascript`，Windows 用 PowerShell

#### 18.3.2 KeyboardService（keyboard.ts）

键盘控制服务，同样支持 robotjs + 系统命令双驱动。

**方法**：

| 方法 | 说明 | 参数 |
|------|------|------|
| `type(text)` | 输入文字 | 文本内容 |
| `pressKey(key)` | 按下单个键 | 按键名称（如 'enter', 'tab', 'a'） |
| `shortcut(keys)` | 执行快捷键组合 | 按键数组（如 `['ctrl', 'c']`） |
| `keyDown(key)` | 按住按键 | 按键名称 |
| `keyUp(key)` | 释放按键 | 按键名称 |

**按键映射**：

每种系统命令都有独立的按键映射函数：

- `toXdotoolKey()` / `toXdotoolModifier()`：通用按键名 → xdotool 按键名
- `toOsascriptKey()` / `toOsascriptModifier()`：通用按键名 → osascript 键码
- `toPowershellKey()` / `toPowershellModifier()`：通用按键名 → PowerShell SendKeys 按键

**支持的特殊按键**：enter, tab, space, backspace, delete, escape, up/down/left/right, home/end, pageup/pagedown, f1-f12

**修饰键映射**：ctrl, alt, shift, cmd/command/meta/win

**文本输入转义**：
- Linux（xdotool）：单引号包裹，内部单引号替换为 `'\''`
- macOS（osascript）：双引号包裹，转义双引号和反斜杠
- Windows（PowerShell）：单引号包裹，内部单引号替换为 `''`

### 18.4 模块入口（index.ts）

`InputModule` 实现 `Module` 接口，激活时创建 `MouseService` 和 `KeyboardService` 实例。

**提供的工具能力**：

| 工具名 | 说明 | 参数 | 返回值 |
|--------|------|------|--------|
| `mouse_move` | 移动鼠标 | `{ x: number, y: number }` | `{ x, y }` |
| `mouse_click` | 点击鼠标 | `{ x: number, y: number, button?: 'left'|'right'|'middle' }` | `{ clicked: true }` |
| `keyboard_type` | 键盘输入 | `{ text: string }` | `{ typed: true }` |
| `keyboard_shortcut` | 执行快捷键 | `{ keys: string[] }` | `{ executed: true }` |

### 18.6 代码规范

- **双驱动策略**：优先 robotjs（原生性能），降级系统命令（零依赖）
- **三平台支持**：Linux（xdotool）、macOS（osascript）、Windows（PowerShell）
- **超时保护**：所有 `execSync()` 调用均设置 5000ms 超时
- **错误处理**：操作失败时记录日志并抛出异常
- **依赖加载**：robotjs 通过 `createRequire` 动态加载，失败时静默降级
