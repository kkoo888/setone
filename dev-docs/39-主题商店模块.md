> **前置依赖**：无

> **说明**：统一主题管理——明暗模式切换 + 配色主题浏览/导入/应用

| 资源限制 | 64MB / 5% CPU |

## 能力声明（provides）

| 类型 | 名称 | 说明 |
|------|------|------|
| tool | `theme_list` | 获取所有主题列表（已导入 + 可下载） |
| tool | `theme_apply` | 应用指定主题 |
| tool | `theme_import` | 从 JSON 文件导入主题 |
| tool | `theme_delete` | 删除已导入的自定义主题（内置主题不可删） |
| tool | `theme_export` | 导出主题为 JSON 文件 |
| event | `theme:changed` | 主题切换通知，包含 mode 和 colors |

## 配置项

```json
{
  "themesDir": "themes"
}
```
