## 技术栈

- **桌面框架**：Electron 33 + electron-vite 2.3
- **前端**：React 18.3 + Zustand + TypeScript 5.7
- **构建**：Vite 5.4
- **AI**：Ollama（本地大模型）
- **存储**：SQLite（better-sqlite3）
- **测试**：Vitest + Playwright
- **代码规范**：ESLint 9 + Prettier
