## 核心架构

### RAGEngine
RAG 问答引擎，实现混合检索 → LLM 精排 → AI 生成回答：
- `ask(question, topK)` — 混合检索（向量+BM25）→ LLM Reranker → AI 回答
- `setNetworkEnabled(enabled)` — 控制联网状态
- 系统提示词引导 AI 仅基于参考资料回答，引用来源

### VectorStore
向量存储层，基于 Vectra 本地向量数据库：
- `indexDocument(docId, text, metadata)` — 文档分块 + 嵌入向量化
- `searchHybrid(query, topK)` — 混合检索：向量余弦相似度 + BM25 关键词匹配
- `deleteDocument(docId)` — 删除文档及其所有分块

### TextExtractor
文本提取器，支持多种文件格式：
- `.md`, `.txt`, `.json`, `.csv`, `.ts`, `.js`, `.py`, `.yaml`, `.html` 等纯文本
- `.pdf` — PDF 文本提取
- `.docx` — Word 文档提取

### DatasetCatalog / DatasetDownloader
数据集广场功能：
- 远程数据集目录浏览
- 数据集下载与导入
- 下载状态追踪

| tool | `kb_reindex` | 重建索引（换模型后重新向量化） |

| tool | `kb_dataset_download_status` | 获取下载状态 |
